# LM_P041 (scans 401–410): second-pass changes

Both halves of every scan were read at the archive's resolution, twice: once by the first run of this pass, which was cut off after the table below reached row 75, and again, line by line, by the run that completed it. Enlarged crops are in `second_pass/work_LM_P041`. The first run's crops are `m401a.jpg` … `mfin3.jpg`, plus the rotated margin notes `m404m.jpg`, `r404.jpg`, `r410a.jpg` and `r410b.jpg`. The second run's montages are `v401_402.jpg`, `v402_403.jpg`, `v402_404.jpg`, `v402_404b.jpg`, `v405_406.jpg`, `v407.jpg`, `w405_406.jpg`, `w407.jpg`, `hats.jpg` (every double-hatted T of the package side by side), `g408_410.jpg`, `g410b.jpg` and `g407le.jpg`; the bracketed numbers [n] in the evidence column refer to their tiles.

Witnesses:
- CSG = `CSG_G103d_draft_2026-02.txt`, ll. 7994–8192. Its text layer loses primes and some symbols throughout (π′ → π, K′ → K, a′ → a, ≠ → =).
- IUT = `IUT_galoisI_historical_witness.txt`, ll. 9184–9380.
- Carmona = `Carmona_Kuenzer_207page_historical_witness.txt`, ll. 3470–3605.
- TOC = `Grothendieck_Circle_tableLM.txt`. The whole package lies in §32, "Retour sur les aspects arithmétiques du bouchage de trous", pp. 200–220; no heading falls in it.

Line numbers count the manuscript lines of each scan.

Rows 1–75 come from the first run. Each was rechecked on the images and confirmed, except rows 13, 53, 54 and 75, which are given here in their revised form. Rows 76–84 are new.
