# LM_P07 (cote 140-2, scans 61–70): second-pass changes

I read both halves of every scan and compared every line of the first pass with them. Enlarged crops are in `second_pass/work_LM_P07` (index at the end). The scans hold part of §8, "Réflexion taxonomique" (the Circle table puts §8 at p. 25 and §9, "Structure tangentielle en les s ∈ S", at p. 34). They contain the end of the modified definition of morphisms, case III (n′ = 0, n = 1), case IV a)–d) (n = n′ = 1), "Réductions élémentaires" and "Cas où les E_i → Γ surjectif". The upper numbers 29–33 stand on scans 62, 64, 66, 68 and 70.

Witnesses. CSG and IUT cover all ten scans. Carmona–Kuenzer covers only scans 68–70 (ll. 1036–1083), because its cases I)–IV) are left blank. The Circle table gives section titles only. Text extraction loses primes, ≠ and some bars in all of them (e.g. CSG "si n = 0" for n ≠ 0); such losses are not counted as witness errors.

- "sss" stays as written.
- A vertical equality between an insertion and the symbol below it is set as `\begin{gathered}…\rotatebox{90}{$=$}…\end{gathered}`.
