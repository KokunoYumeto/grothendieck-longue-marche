## Notes added in the second pass

**S01 — scans 137, 148 — own idea (verification of (309), hence (296) and (310)) — second pass, own.** For any abelian
group I with trivial action, 0 → I → I³ → M₀⊗I → 0 (M₀ = ℤ^{{0,1,∞}}/ℤ) and Shapiro's lemma (I³ is induced from 𝔖₂)
give H⁰(𝔖₃, M₀⊗I) = Ker(H¹(𝔖₃,I) → H¹(𝔖₂,I)) = 0 and H¹(𝔖₃, M₀⊗I) = Ker(H²(𝔖₃,I) → H²(𝔖₂,I)) = 0, because restriction
to a 2-Sylow subgroup is injective on these 2-primary groups (both are I[2], resp. I/2I). So (309) holds for every I,
(296) is the case I = ℤ, and since 𝒥⁰ = 𝔾_m⊗M₀ with M₀ free, E₂^{p,0} = H^p(𝔖₃, M₀⊗𝒪(S)*) and E₂^{0,1} = H⁰(𝔖₃, M₀⊗Pic S)
vanish, which gives (310) on every S without Pic(S) = 0.

**S02 — scan 147 — own idea (on the « Attention » note and the lower note) — second pass, own.** The cyclic-ratio map
(x₀,x₁,x_∞) ↦ (x₁/x_∞, x_∞/x₀, x₀/x₁) satisfies φ(τx) = τφ(x)⁻¹ for a transposition τ, so it identifies 𝔾_m^{{0,1,∞}}/diag
with the kernel of the product twisted by the sign character. With that twisted action the invariants (x,x,x) need
x³ = 1 and x² = 1, hence are trivial on any base; with the untwisted action one gets μ₃(S), and on the lattice level
H¹(𝔖₃, sum-zero lattice) ⊇ ℤ/3 ≠ 0. This is the content of the lower margin note: the page's « x³ = 1 » calculation
is right over ℤ but would need H⁰(S, μ₃) = 1 on a general base.
