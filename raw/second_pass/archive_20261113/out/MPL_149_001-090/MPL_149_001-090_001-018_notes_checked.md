## Own notes (second pass)

**O1 — scans 004–005 — reading question with mathematical consequence (mine).** With "sép." live on scan 004, the
point of Π_{K'} is "ou clôture sép. K̄' de K'", and the induced point of Π_K is "K̄ = clôture alg. sép. de K dans
K̄'". This is the same "clôture alg. sép." as on scans 005 and 007. The first pass's reading ("clôture alg. de K dans
K̄'") would take a closure that is not separable in characteristic p, and scan 004 still treats arbitrary fields (the
restriction to characteristic 0 comes on scan 005). Confidence: medium, because it rests on the reading of "sép".

**O2 — scan 013, display (14) — own idea (mine): the "(sauf erreur)" equalities hold.** Take K finitely generated over
ℚ with transcendence degree n, and k the algebraic closure of ℚ in K. Then π_{K̄/K} = G_{Kℚ̄}, and Kℚ̄ is finitely
generated of transcendence degree n over the algebraically closed field ℚ̄, so cd π_{K̄/K} = n. Also
cd_ℓ E_{K̄/K} = n + cd_ℓ G_k = n + 2 for ℓ odd. Both follow from Serre, *Cohomologie galoisienne*, II §4.2 (the bound
cd_p(K) ≤ tr.deg + cd_p(k), with equality for finitely generated extensions when cd_p(k) is finite) and §4.4 (cd_ℓ of
a number field is 2 for ℓ odd). So n = cd π_{K̄/K} = cd_ℓ E_{K̄/K} − 2, as he says. The ℓ-exponent now read on
E_{K̄/K} before (14) states the same thing ℓ by ℓ. For ℓ = 2, cd_2 is infinite as soon as K has an ordering, which
explains "si ℓ ≠ 2". Confidence: high.

**O3 — scans 012–015 — own idea (mine): (13) is a limit with surjective projections, which closes the proof of
Théorème 1 for π.** For a dense open U_j ⊂ U_i, both Ū_j and Ū_i are normal and connected (U_i is geometrically
connected over k, scan 011). So π_1(Ū_j) → π_1(Ū_i) is surjective (SGA 1, Exp. V, Prop. 8.2), and so is
π_{K̄/K} → π_i, by the same proposition at the generic point. The argument of A015.4 then shows that π_{K̄/K} has
trivial centralizers of open subgroups once every π_i has. By the Corollaire on scan 015, that holds when every free
factor has rank ≥ 2, which can be arranged by shrinking the cofinal U_i to hyperbolic elementary fibrations. This
removes the rank gap of A015.1 without changing his statement. Confidence: high for the surjectivity; medium for the
existence of hyperbolic elementary neighbourhoods over a number field, which rests on the references in A011.1 and
A013.4.

**O4 — scan 014 — own idea (mine): both inputs of the proof of the Corollaire hold.** By Artin–Schreier, an element
≠ 1 of finite order in G_ℚ is an involution whose fixed field is real closed. ℚ has a single ordering, so all real
closures of ℚ inside ℚ̄ are conjugate, which gives "les conjugués de τ". The centralizer C of τ normalizes ⟨τ⟩, so it
acts on R = ℚ̄ ∩ ℝ. A real closed field algebraic over ℚ has no nontrivial automorphism: an automorphism preserves
the ordering, and each element is determined by its position among the rationals. Hence C ⊂ Gal(ℚ̄/R) = {1, τ}, which
is "réduit à (1,τ)". Confidence: high.

**O5 — scan 015 — own idea (mine): the second "à vérifier".** A free profinite group is projective, so cd ≤ 1, and a
profinite group of finite cohomological dimension has no torsion (Serre, *Cohomologie galoisienne*, I §3.3). This
settles "il n'y a pas d'élément d'ordre fini ≠ 1" in every rank. The first "à vérifier" (trivial centre) holds only in
rank ≥ 2 (A015.1). Confidence: high.
