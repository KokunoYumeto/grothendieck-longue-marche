## Witnesses: their own errors and differences noticed

- 495, §49 heading. Carmona–Kuenzer, running head "§ 49. — LES GROUPES ρ,σ GÉNÉRAUX": the M is lost. The ink reads "les groupes M_{ρ,σ} généraux".
- 495, §49 heading. Grothendieck Circle table: "49. Les groupes Mρ,σ généraux". The ink reads "49. Homomorphismes de M_{0,3}, les groupes M_{ρ,σ} généraux". This is a later, shortened title, not a misreading.
- 495, margin. The table titles section I "Préliminaires heuristiques" (p. 550). The ink margin note reads "Où on se met dans le bain…" and, at length, "Toute cette section I semble entièrement inutile pour la suite…". This is a later retitling.
- 502, margin. The table gives "II. Les groupes Mρ,σ etc. "sans signes"; … 553". The ink margin heading is "Les groupes M_{ρ,σ} etc", without "sans signes".
- Table, §48 II: "L'équation ζ = η 1(µ − 1)" loses ε and the exponent form. The ink on 498, (26) is ζ = η ε_1^ν with ν = (μ−1)/2.
