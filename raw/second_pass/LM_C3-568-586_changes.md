# LM_C3-568-586: second-pass changes (scans 568–586)

**Witness coverage:** none of the text witnesses reaches these pages. CSG and IUT end around manuscript p. 300
(§§37–38), and Carmona–Kuenzer covers the same range. These scans are §49 V, upper numbers 588–596 (lower 567–585).
Searches for distinctive words of the package found nothing from these pages: "prolongeable", "sauver la mise",
"multiplicativement", "Normalisation de", "rectification plus", "Reprenons la d", "fait ce qu'il fallait". The hits
for "draconienne", "cas universel", "fonctorialité" and "signature" all belong to §§1–37.
