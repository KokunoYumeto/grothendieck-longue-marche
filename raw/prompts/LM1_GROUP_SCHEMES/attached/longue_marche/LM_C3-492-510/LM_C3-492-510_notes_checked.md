## B. Second-pass notes (own)

**B1. 501/504 — own idea (verification), confidence high.** For u = u_{ζ,η} and u' = u_{ζ',η'}, (u'∘u)(ρ) = u'(ζρ) = u'(ζ)u'(ρ) = u'(ζ)ζ'ρ, so ζ'' = u'(ζ)ζ'; in the same way η'' = u'(η)η'. This is (13) on 504, so the law on Σ is the transported composition law and not the componentwise one. That fits the corrected "déduite par transport de structure" on 501.

**B2. 505 — own idea (verification), confidence high.** In B ⋉ C, where int(h) acts on C by c ↦ hch^{-1}, the element i(g) = int(g)·g^{-1} centralises C, and i(g)i(h) = int(g)int(h)·(h^{-1}g^{-1}h)h^{-1} = i(gh); so i is a homomorphism. An element c ∈ C lies in i(L_0) exactly when c = g^{-1} for some g ∈ L_0 with int(g) = 1. This proves (18): Ker(C → G_{ρ,σ}) = L_0 ∩ Centr(C) = Ker(L_0 → B_{ρ,σ}).

**B3. 509 — own idea (author's slip), confidence high.** In (31) the ink has α(ρ)ρ^{+1}, while the same line gives αρ(α)^{-1} = [α, ρ], which equals α(ρ)ρ^{-1}, as in 500 (34) and 502 (5). The "+" is a slip or a malformed minus. The transcription keeps it as `\unsure{+1|-1}`.

**B4. 509 — own idea (proof sketch for (34)), confidence medium.** For a ∈ Z_ρ, [ua^{-1}, ρ] = ua^{-1}ρau^{-1}ρ^{-1} = [u, ρ], and likewise for b ∈ Z_σ; hence (ua^{-1}, ub^{-1}) ∈ g_{ρ,σ} for u ∈ B_{ρ,σ}. Conversely, given (α, β) ∈ g, take u = u_{ζ,η} with ζ = [α, ρ] and η = [β, σ] (hypothesis (10)). Then a = α^{-1}u ∈ Z_ρ and b = β^{-1}u ∈ Z_σ, which inverts (34), with uniqueness from (10) a). The argument needs Z_ρ and Z_σ as defined in (33), not the T_ρ and T_σ written in (34).

**B5. 510 — own idea (verification), confidence medium.** Since C = Ker δ_G, δ_G(ua^{-1}) = δ_B(u)δ_ρ(a)^{-1}, which is trivial exactly when δ_B(u) = δ_ρ(a), and likewise for ub^{-1}. So (34) maps the set of (36) onto g_{ρ,σ} ∩ (C × C) = Sg_{ρ,σ} (30). Hence (38) is the restriction of (34), and its target "S_0g_{ρ,σ} (défini dans (27))" agrees with (30) under (18).
