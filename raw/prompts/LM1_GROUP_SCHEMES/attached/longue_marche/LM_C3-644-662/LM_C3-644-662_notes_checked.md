## Second pass: own notes

1. **Scans 646–647 — claim without proof; own note.** By the cancelled Proposition's filtration, |𝒢/Π₀| = |μ|·|𝒢₃|·|μ| = 2·6·2 = 24, which is the "même ordre 24" used to make the injective (46) an isomorphism. The order of N_ρ*/M°(−j̄) is not computed on these pages.
2. **Scan 646 — implication; own note.** With M′ = Ker ε₃, M″ = Ker ε₂ and M° = M′ ∩ M″ (scan 643: M°(0) = {ε₂ = ε₃ = 1}), the last display M′(−j̄) ∩ M″ = M°(−j̄) is immediate. The substantive step is N_ρ* ∩ M₀! = Z!_{ρ0} = M′(−j̄), taken from earlier pages.
3. **Scan 652 — conjecture (tentative); own note.** Both clauses carry "peut être": in the adelic group-scheme case ρ, σ, τ may generate 𝒢⁺ only up to a finite group, i.e. an open subgroup. No hypothesis is given that would decide it, and the constructions that follow assume generation.
4. **Scan 653 — slip; own note.** "il est clair que la condition c′) définit un sous-groupe": there is no c′); the condition just rewritten is b′) (5*). An edition for readers should flag it, not alter the transcription.
5. **Scan 654 — slip; own note.** In the addition to (6) the ink has α_𝒢(α′) = ε′₃; (7) uses ε_𝒢(α′), so α_𝒢 is a slip for ε_𝒢.

So the cancelled remark holds with a) and b) exchanged: for a) to be multiplicative it suffices that u(σ) ≡ ±σ (𝒢^♮). The ink has b) … a).
