# Actual norm identity after the A.211 normalization

Date: 2026-11-16. Root continuation note; no new numbered statement.

Use exactly the actual fields, automorphisms and normalized elements of A.211. Thus w=u x, N_s(w)=f sigma(a), f lies in F, div_M(x)=j_h(D), and 3D=div_E2(f). Set beta=sigma(a) f/N_h(x). Since N_h(j_h(D))=3D, the numerator and denominator have equal divisors on E2. Consequently beta is an actual E2 unit. The commuting automorphisms h and s give the literal identity

    N_s(N_h(u)) = N_h(N_s(u))
                 = (sigma(a))^3 / N_h(c)
                 = (sigma(a) f/N_h(x))^3
                 = beta^3.

Here c=x^3/f and N_h(c)=(N_h(x)/f)^3. The element N_h(u) is an actual unit of the fixed field Omega^h=K3(zeta); the norm in the first line is its actual cubic norm to E2. This identity retains both the ideal norm and field norm without changing representatives. It has not yet identified the class of beta or the coordinates of c. The fact that beta cubed is a unit norm alone supplies no additional restriction: cubing any E2 unit already gives its norm after scalar inclusion in this cubic extension.

For an element c in the necessary subspace represented by the A.211 construction, the actual cube root N_h(x)/f of N_h(c) is specified. Multiplication of c by the cube of an M unit multiplies this root by its h-norm, up to a cube root of unity; the latter ambiguity belongs to the unit norm image because N_h(z)=zeta. This gives a well-defined class for those constructed c in U_E2/N_h U_M. Its evaluation requires information beyond the already computed mod-three h-norm matrix. No equality with the unevaluated secondary map is asserted.
