## Exact common-log lattice

Use the normalized log vector (2 log|embedding(u)|) on complex pairs,
with Euclidean metric, in the sum-zero hyperplane. For any cubic Li/F,
if log(u) belongs to the base real log space V_F, then sigma_i(u)/u
has every conjugate of modulus one; it is an algebraic integer unit,
so Kronecker makes it a root of unity.

For E2,j/F this ratio lies in mu3 and hence u^3 is an F-unit.
The Kummer kernel for F -> E2,j is generated by d^2 alpha zeta^j.
Its valuation at a prime over11 is2 modulo3. A nontrivial power
cannot be the class of a global unit. Hence u^3=v^3 for an F-unit v;
u/v lies in mu3 already contained in F, so u itself lies in F.
Thus Lambda_E2,j intersection V_F is exactly Lambda_F.

For Fprime/F, write h(u)/u=z^k. Its h-norm equals z^((1+4+7)k)=z^(12k)=zeta^k,
so k is divisible3. Dividing u by an appropriate power of z makes
it h-fixed. This changes no log vector. Therefore the same exact
intersection Lambda_Fprime intersection V_F=Lambda_F holds.

## Covolume of the actual sum map

The orthogonal G-representation is V_M=V_F direct-sum W_0 direct-sum
W_1 direct-sum W_2 direct-sum W_3, with dimensions2 and6 each.
V_Li=V_F direct-sum W_i. Distinct W_i are orthogonal because their
nontrivial C3^2 characters have different kernels.

For the sum map from direct-sum_i V_Li to V_M, the lattice kernel
is precisely Lambda_F tensor A3, namely tuples of base log vectors
whose sum is zero. Its Euclidean covolume is
4^(dim V_F/2)*covol(Lambda_F)^3 = 4*covol(Lambda_F)^3.
The sum map restricted to the perpendicular kernel complement has
determinant 2^(dim V_F)=4. These two factors cancel. Therefore,
with all lattices embedded in V_M,

  covol(B_log)= product_i covol(Lambda_Li)/covol(Lambda_F)^3.

Each Li -> M repeats each log coordinate three times, multiplying
lengths by sqrt3 and its rank-eight covolume by3^4. F -> M repeats
nine times, multiplying its rank-two covolume by3^2. In native
log metrics this gives the factor3^(16-6)=3^10:

  covol(B_log)=3^10 * product_i covol_native(Li)
                         /covol_native(F)^3.

For a totally imaginary field with r2 complex pairs,
covol_native(L)=sqrt(r2)*R_L. The factor converting the last formula
is sqrt9^4/(sqrt27*sqrt3^3)=3. Hence, for the ordinary free-unit
index I=[Lambda_M:B_log],

  product_i R_Li/(R_M*R_F^3) = I/3^11.

The A199 index proves v3(I)=6, so the regulator ratio has valuation−5.
