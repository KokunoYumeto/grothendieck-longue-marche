| Manuscript sign or convention | LaTeX reading | Handling |
|---|---|---|
| Script structural sheaf O | `\mathcal{O}` | Distinguish from zero; retain indices. |
| Ideal sheaf, barred serif I | `\mathcal{I}` | Distinguish from plain module J. |
| Plain module J | `J` | Subscripts and bars checked locally. |
| Graph, capital Greek gamma | `\Gamma` | Distinguish from script letters and upper-case T. |
| Uniformizer, pi | `\pi` | Exponent read locally, including negative powers. |
| Obstruction, xi | `\xi` | Repeated uncertainty is retained where ink is overwritten. |
| Double quotation marks | two backticks and two apostrophes | Guillemets only if drawn. |
| Genuine prime / exclamation exponent | `'` / `^!` | Never infer one from the other. |
| Underline / double underline | `\uline` / `\uuline` | Applied to the visibly marked words. |
| Deleted / inserted text | `\deleted` / `\inserted` | Transcribed in situ; neither silently suppressed nor normalized. |
| A horizontal connecting stroke without certain arrowhead | `\unsure{\longrightarrow\vert\text{—}}` (with a literal `|` separator in actual readings) | Direction inferred only when the ink supports it. |
