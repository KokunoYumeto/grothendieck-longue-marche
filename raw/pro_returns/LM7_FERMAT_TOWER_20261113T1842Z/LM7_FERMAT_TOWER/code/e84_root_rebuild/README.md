# Independent E84 rebuild

Run `python e_ramified_capitulation.py --gp /absolute/path/to/gp` from any directory. All eleven required source files are included. The driver creates the original relative directory layout temporarily, rebuilds all ten GP stages and checks the complete rational and integral certificates. Stored stdout and JSON are actual fresh outputs. The separate binary-object comparator records equality of all eleven components despite different serialization bytes; its original executed paths name the author and root scratch trees.
