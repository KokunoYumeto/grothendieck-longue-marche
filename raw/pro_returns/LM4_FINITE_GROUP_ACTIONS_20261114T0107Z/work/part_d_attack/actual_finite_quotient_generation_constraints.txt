1. An actual permutation inequality, with all subgroup maps
----------------------------------------------------------

be any continuous onto map to a finite group. Let Omega=A/M be a
transitive A-set, n=|Omega|, and let U=q^(-1)(M). The explicit map

is an equivariant bijection. Thus [E:U]=n. Define

Restrict the actual D76 exact sequence to U:
  0 -> Delta_T -> P=direct_sum_i k[[E/T_i]] -> k -> 0,
  Delta_T|U = k[[U]]^(2n).
The second equality uses D76's full Delta_T ~= k[[E]]^2 and the
finite coset decomposition of the free k[[U]]-module k[[E]].
For every double coset U g T_i, the map
  U/(U cap g T_i g^(-1)) -> U g T_i/T_i,
  u(U cap g T_i g^(-1)) -> u g T_i
is an equivariant homeomorphism. Inversion U g -> g^(-1)U identifies
the right T_i-orbits on U\E with its left orbits on E/U. Hence f_i
of these U-orbits have stabilizer a full C2 and (n-f_i)/2 have trivial
stabilizer. This includes the case q(t_i)=1.

Shapiro for these displayed compact permutation modules gives
  dim H_1(U,P)=S,
  dim H_0(U,P)=(3n+S)/2,
  dim H_0(U,Delta_T)=2n,
  H_1(U,Delta_T)=0.
The actual homology long exact sequence is therefore
  0 -> k^S -> H_1(U,k) -> k^(2n)
      -> k^((3n+S)/2) -> k -> 0.
All terms and arrows are restrictions or derived coinvariants of the
original sequence, with no replacement of the stabilizer U. Exactness
proves
  dim H_1(U,k)=(n+S+2)/2,
  dim coker(k^S -> H_1(U,k))=(n-S+2)/2 >= 0.
In particular every such ACTUAL quotient/action satisfies

The same conclusion follows for each orbit of a nontransitive set.
No sufficiency statement for generation is deduced from (1).
