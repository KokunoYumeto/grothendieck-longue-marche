# Reading workflow

Three new independent agents are created for each scan, with no inherited conversation. Each receives only that page’s images, page excerpts of C/H and C’s doubt/notes guide, the conventions, and a snapshot of the accumulated notation table. Reader outputs are isolated in readers/scanNNN/Rn; each is told not to inspect any other reader. The main reader compares their returns and personally views crops for disagreements. No OCR or external research is used.
