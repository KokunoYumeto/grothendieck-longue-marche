# A reflection-symmetric line countermodel to a broad relative shortcut

This is an auxiliary counterexample obtained from the proved B76 model.
It is NOT the actual mu5 arrangement and does not decide either actual
fixed-lifting gate.

In affine coordinates (lambda,z), let the source line be lambda=0 and
let F(lambda,z)=(-lambda,z+lambda). This is an involutive linear map
fixing the source pointwise. Let the retained divisor D be the union of
six lines

lambda=1, lambda=-1, z=0, z=lambda, z=-lambda, z=-2lambda.

It is F-invariant. Let A={z=1}, B=F(A)={z+lambda=1}. They are distinct
lines with their unique transverse intersection (0,1) outside D. All
finite incidences are ordinary intersections of lines; no tangent
parabola is used. The source complement before filling A is always
C minus {0,1}, and after filling A it is C*.

Write Xnew=C² minus D, Ynew=Xnew minus A, and Wnew=Ynew minus B.
Forgetting the three extra retained lines

lambda=-1, z=-lambda, z=-2lambda

maps these actual source/filling data to the B76 model with retained
Dold={lambda=1,z=0,z=lambda} and deleted A={z=1}. The source spaces and
source maps are unchanged. The map pi1(Ynew)->pi1(Yold) is onto: a loop
can be perturbed away from the extra complex codimension-one divisors.
The filling kernel Rnew is normally generated by one actual meridian
of A, and its image is all of Rold because the ambient map is onto and
the same meridian normally generates Rold.

B76 identifies Yold with (C minus {0,1})² by
(z,r=(lambda-z)/(1-z)). The source lambda=0 is the graph of the Mobius
map r=z/(z-1). Its group image is a graph F2 in F2 times F2. The filled
old group is Z³. In particular a nontrivial first-factor commutator
([a,b],1) lies in Rold but outside the whole old source image, and is
separated by the graph-aligned S3 times S3 quotient. If the new source
kernel image were all of Rnew, its image under forgetting would make
the old source image contain Rold, a contradiction. Hence the new
source-kernel equality fails.

The same finite quotient proves failure for actual compact source
images. The completed map Rnew->Rold is onto: both are the closed
normal meridian kernels and the ambient completed map is onto. Thus
the separating first-factor commutator has an actual compact lift in
Rnew, while every compact source element maps into the closed graph
subgroup. No completion of an abstract infinitely generated kernel is
substituted here.

This proves that the following collection of facts does not by itself
imply the desired relative source equality: a literal linear involution
fixing the source, invariant retained line boundary, distinct deleted
mirror lines, and the full degree-product number of transverse mixed
intersections outside the retained boundary. It does NOT specify
whether the post-critical fixed-source projection or fixed-element
lifting is responsible for failure in this model. It also does not
satisfy every further bundle/incidence property of the actual mu5
configuration, and no such identification is made.

The exact reflection, retained-line permutation, source exclusions,
transverse intersection and finite commutator witness are checked by
check_reflection_relative_countermodel.py. The topology transfer uses
the already proved B76 normal-meridian comparison, not an unproved
relative product theorem.
