1. Scope of the target classification

The proof of C.37.9 uses exactly path connectedness, transitivity and
metabelianness of the actual image in the intrinsic homeomorphism group.
It does not use membership of the orbit in X_2 after the metabelian
identity has been obtained. Its application to an arbitrary metabelian
nonopen orbit in C.52 is therefore valid. The original finite-word paths
are intrinsically compact-open continuous by C.28, so path connectedness
is available in that actual image topology.

The resulting groups are the full translation group, full positive
affine group, or full circle rotation group after the stated conjugacy.
In particular C.52 uses a global logarithm only in the simply connected
translation or positive affine group. It uses a based real lift, not a
logarithm of a projected circle endpoint, in the circle case.

2. Exact comparison of the real lifted target groups

For each actual quotient the equation F a_t = b_t F specifies the based
target path on the real cover. The source and target covering maps from
C.42--C.44 are retained. The endpoint b_1 is the identity: for a circle
this is the established zero-winding statement, rather than an arbitrary
choice of lift of the identity.

The group T generated by the b_t acts transitively on the real line.
Every one of its orbits is connected because each word has a path from
the identity. A proper orbit interval has a finite endpoint fixed by all
words, which would give a fixed point of the actual transitive target
action after projection. A one-point orbit is excluded by the same
argument. Thus the interval is the whole real line.

For a line target T is exactly the conjugate of the actual image. For a
circle target the projection T -> G|_B is onto. If G|_B is metabelian, a
rotation conjugacy lifts to the real line and each based b_t becomes a
translation. Transitivity makes T all translations. Conversely a
metabelian T has metabelian quotient. This proves the equivalence used
to select the branch of C.52.5.

This equivalence is especially important when two distinct actual
boundary quotients have the same real fibre partition but have different
downstairs target types. Their real maps differ by a line homeomorphism,
which conjugates their entire based target paths and generated groups.
Their branch choices therefore agree through that exact comparison;
there is no unsupported identification of a circle image with a real
image.

3. Naturality and based circle data

Conjugation by any line homeomorphism, including a decreasing one,
identifies the actual target groups and preserves metabelianness. In the
Lie cases it is a continuous Lie-group isomorphism and intertwines the
exponential maps and their unique logarithms. The median branch has the
already proved naturality. Hence C.52.5 is natural under every target
comparison used later.

A target homeomorphism commuting with the original path centralizes T.
It consequently commutes with the exponential fractions, which lie in
T, as well as with the median fractions. The specified based circle
path is retained throughout. At an intermediate identity endpoint its
real translation may be a nonzero integer and is scaled as that real
translation. Only its final endpoint is forced to zero. This is exactly
the convention in C.50 and removes a possible ambiguity in the claimed
agreement on X_*.

4. The two-partition replacement

In the full-plane domain, the independent target homeomorphisms give an
actual homeomorphism with continuous inverse. In the half-plane and
strip domains the original coordinate paths are identical, hence their
generated groups and selected fractions are identical too. Strict order
is preserved. In the strip, unit translation centralizes the original
path and therefore the chosen fraction; the second strict inequality is
also preserved. The same facts hold for inverse maps.

Every source operator lift permutes the full two-element partition
family, and its induced line homeomorphisms conjugate the two based
paths exactly. Naturality proves commutation of the replacement with
that lift, including the exchange case and all source deck maps. It
therefore descends through the specified source cover. Any other actual
quotient is a line reparametrization of a selected coordinate, so its
exact lifted equation follows before descent through its own target
cover. This verifies C.52.2 for the full family, not merely for the two
chosen representatives.

5. The one-partition replacement

I compared C.52.6 with every C.48 normal form. The fibre interpolation is
unchanged. Its equations for unit fibre translations, a further
(epsilon u,r+d), and a real fibre kernel with further (lambda u,r+d)
are preserved by linear interpolation, including negative epsilon or
lambda. In each case the base equation is commutation with a stated
translation, hence survives the replacement by C.52.5.

For all real base translations and for the dense lattice base image,
the original base path is a translation path. The replacement is exactly
translation by (1-s)c_t. Independence of r in the first case, and the
exact affine lattice equation in the second, remain unchanged. The
trivial operator case adds no equation. The transitive two-dimensional
operator case belongs to U_2 and is excluded by the stated disjointness
from X_*; it is not an omitted case of the new construction.

The base family has jointly continuous inverses. The fibre maps remain
increasing convex combinations of increasing surjections; the C.48
bracketing argument proves their inverse continuity with parameters and
basepoint varying. Commutation with every source deck map and every
operator lift gives the exact descended family. Reparametrization
naturality supplies every quotient equation in the one-partition case.

6. Cocompact interior-to-frontier continuity

The compact fundamental set C with Q C = O is the exact compact set of
C.51. For x_n = q_n y_n approaching the frontier, compactness gives a
subsequence y_n -> y inside C. The actual global h_n approximate q_n
uniformly on the compact union of C and all its images and inverse
images under the constructed family. This is an allowed compact-open
neighbourhood condition in the actual restricted closure Q.

The open L-orbit map supplies l_n -> 1 with l_n y = y_n. Exact
commutation gives h_n y = l_n^{-1} h_n y_n -> z. C.42 evaluation then
gives compact-open convergence h_n|_O -> Phi_z^y. The explicit C.51
basepoint comparison identifies this map with an actual quotient in the
full family, or with the constant map for a fixed target.

The new exact quotient equation, together with the uniform approximation
on images of C, gives C.52.8. Every subsequence has a further subsequence
with this same prescribed limit, so the interior-to-frontier convergence
holds for the entire sequence and for varying homotopy parameters.
No global extension of an arbitrary element of Q is used.

7. Frontier-only sequences and inverses

The diagonal argument is valid without continuity of the hybrid
prescription being assumed. For each fixed (s_n,t_n,z_n), the just-proved
interior limit permits an x_n in O within 1/n of z_n whose image is
within 1/n of the prescribed frontier image. These x_n converge to z.
The interior limit for their varying parameters proves convergence of
the original frontier images. Combining interior and frontier terms
proves the full joint continuity on the one fixed closure.

The inverse quotient equation follows by composition with the actual
source and target inverses. The compact approximation set already
contains the required inverse images. The identical interior-limit and
diagonal argument therefore proves inverse continuity as well. Each
piece preserves its actual orbit and has that prescribed inverse, so
the glued maps are bijective homeomorphisms of the entire closure.

8. Agreement, transport and exact remaining scope

The second-derived word identity holds pointwise on U_2 union U_3 and
therefore on its closure X_* for every four original group elements.
Since X_* is G-invariant, each nonopen image there is metabelian. An
open orbit outside that union is disjoint from X_*; distinct open-orbit
closures cannot meet inside a third open orbit. Thus each intersection
under consideration contains only nonopen orbits. Both C.50 and C.52
there use the identical intrinsic Lie image and identical based target
cover path. They agree exactly, including the intermediate circle-angle
case.

On common frontiers C.52 assigns the same rule. Operator transport
identifies the actual target images, their paths and both alternatives
of that rule. Choosing the intrinsic construction on one H-orbit
representative and conjugating is independent of the transporting
element because the full stabilizer commutes with the construction.
Finite closed-set pasting with X_* is therefore valid for both maps and
inverses, with the stated intertwining between a union and its H-image.

The diagonal proof is for a fixed cocompact orbit closure. It does not
claim continuity of the hybrid rule on all of the nonopen locus, uniform
control across infinitely many unrelated compact fundamental sets, or
an extension for a noncocompact proper-operator quotient. The metadata
retains these limits and keeps C.12 open. This scope is correct.
