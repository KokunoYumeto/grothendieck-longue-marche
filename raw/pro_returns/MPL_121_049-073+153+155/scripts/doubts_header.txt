# Notation register and doubts

## Package notation register

The register began with the first page and was reconciled across all 44 pages after the second visual reading, before the supplied context was opened. This table describes transcription conventions, not mathematical identifications supplied by later sources. The fragments preserve genuine changes of notation; consistency does not mean replacing a written sign by a mathematically expected one.

| Manuscript sign or usage | LaTeX encoding | Locations / distinction retained |
|---|---|---|
| Double quotation strokes | two backticks and two apostrophes | Throughout; quotation characters in TikZ option syntax are not manuscript quotation marks. No guillemets are substituted. |
| Double-stroked number alphabets | `\mathbb N`, `\mathbb Z`, `\mathbb Q`, `\mathbb R`, `\mathbb C` | 121:049,055–059,065,070–073; 153:002–003,010. First-pass bold encodings were reconciled against visible doubled strokes. |
| Plain ambient R versus real-number sign | `R` versus `\mathbb R` | Especially 121:070: “Soit R un ensemble (ce sera bientôt …)”; the alphabets are not collapsed. |
| Interval letter and powers | `I`, `I_0`, `I_1`, `I^n` | 121:054–068. Sometimes heavily retraced or doubled; stroke weight alone was not treated as a new mathematical object. |
| Cursive category / function-family capitals | `\mathcal M`, `\mathcal K`, `\mathcal F` | Cote 121; ordinary indexed subset-family `M_n` remains distinct. |
| Special ind-object letter | `\mathfrak X` | 121:054–055; distinct from ordinary X. |
| Closure and interior | `\overline F`, `\mathring T` | 121:049–052. Absent closure bars are not supplied. |
| Greek capitals and graph sign | `\Phi`, `\Gamma`, `\Delta`, `\Sigma`, `\Omega` | No identification of Phi with F, or Gamma with T, is imposed where ink is ambiguous. |
| Lower-case Greek forms | `\varphi`, `\psi`, `\varepsilon`, `\lambda`, `\tau` | Looped phi and epsilon retain local forms; cramped subscripts are marked. |
| Primes | `'`, `''` | Object labels and M′ axioms in 121; the fibre functor becomes visibly `F'` on 155:006,008. |
| Raised exclamation mark | `^!` only if present | No definite such exponent identified in this package. The mark on 153:002 is read `E^1`; readings from earlier packages are not imported. |
| Dual signs | `^\vee`, `^{\vee(k)}`, `^{\vee(k')}` | 155:002–008; base field and prime retained independently. |
| Opposite ring sign | `^o` | 155:006–008; not normalized to `\mathrm{op}`. |
| Checked element | `\unsure{\check u&#124;\widetilde u}` (vertical bar separates alternatives in the actual fragment) | 155:006; diacritic uncertain, not a prime. |
| Raised final-target mark | `\unsure{k^{\wedge}&#124; k'}` (alternative separator) | 155:010; wedge-like mark precedes the mathematically natural prime alternative. |
| Underlined O with subscript | underlined `\mathcal O_{k_0}` / `O_{k_0}` alternatives | 153:002; O visibly separate from k₀, not underlined k₀ alone. |
| Normalizer / generating ideal | `\widetilde J`, `J`, `\mathfrak j` | 155:002; the lower-case j alphabet is less secure than the case distinction. |
| Limit with left-pointing stroke below | `\varprojlim` | 121:054–055,059; initially plain or underlined readings corrected against ink. |
| Limit with right-pointing stroke below | `\varinjlim` | 121:055; 121:065 retains an underline alternative. |
| Unheaded connection | hyphen relation or TikZ `dash` / `no head` | No arrowhead supplied solely from mathematical intent. |
| Arrow direction / hook / double direction | standard arrow commands and TikZ options | Local directions retained; return arrow on 121:062 remains uncertain. |
| Left-pointing element map | `\mathrel{\longleftarrow\!\vert}` | 155:008; bar at the right, arrowhead at the left. |
| Circled numbering | `\textcircled{...}` where needed; author numbers in `\mspage` | Overwritten axiom number at 121:072 remains doubtful. |
| Equality-like prose shorthand | `=` or `\equiv` | Retained as a sign; possible “même” expansion appears only below. |
| Raised t in prose | `$^{\mathrm t}$` | Abbreviation ending, not expanded word. |
| Single / double underline | `\uline`, `\uuline` | Includes printed broken underline rules; individual typewriter underline dashes are not text. |
| Insertions / deletions | `\inserted`, `\deleted` | Insertions follow the caret/leader where discernible; uncertain attachment recorded below. |
| Foot foliation | `\margin{...}` | Distinguished from author sheet numbers; hand attribution not assumed. |
| Printer characters / identifiers | `\texttt`, arrays / tables | Reused sheets in 153 include repeated banners; uncertain border-star counts are flagged. |
| TikZ alignment inside macro arguments | `ampersand replacement=\&` | Technical syntax only; no written object or edge changed. |

## Reading confidence

High means the feature can be distinguished positively in the image, including an apparently erroneous or unfinished form. Medium means a plausible visual reading with unresolved detail; low means cramped, cancelled, overlapped, damaged, or insufficiently differentiated ink. Confidence is not a numerical estimate of transcription accuracy and is never based on mathematical plausibility alone.
