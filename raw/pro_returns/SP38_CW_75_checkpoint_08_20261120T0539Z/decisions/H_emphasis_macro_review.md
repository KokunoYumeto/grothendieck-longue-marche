# Witness H emphasis convention

Checked from the supplied hua/transcripts/preamble/grothendieck.sty while scan012 readers worked. Its comments explicitly say that the transcriptions use `\emph` for Grothendieck’s own emphasis, and `normalem` preserves that rendering. H uses `\uncertain` for editorial reading doubt, implemented with `\uline`; that is a separate semantic role.

For collation, an H `\emph` that records the same author-emphasized word as C/final `\uline` is treated as a macro-convention equivalent. The final transcription still reproduces the actual underline seen in the scan. A word whose emphasis is entirely absent in H, an omitted second underline, or a different span remains a substantive state/placement question. No existing page text was altered by this convention review.
