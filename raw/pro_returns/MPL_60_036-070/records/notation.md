# Notation table

This table records the conventions compared visually across all 35 pages before the transcription was frozen and before the context archive was opened. One reader transcribed and audited every page. Doubt marks remain where the ink does not decide; an apparent mathematical inconsistency is not a warrant to change a sign. Alternatives separated by a vertical bar are readings, not simultaneous mathematical expressions.

| Manuscript sign or convention | LaTeX rendering | Observation / scope |
|---|---|---|
| Typed letters with an explicit underline, usually ideals | `\underline{p}`, `\underline{m}`, `\underline{n}`, `\underline{P}` | The typewritten underline is preserved; it is not replaced with a Gothic alphabet. |
| Typed ordinary capitals for number fields and integers | `Q`, `Z`, `N` | Ordinary alphabet, distinct from heavily drawn handwritten capitals. |
| Heavily drawn handwritten number-field/integer capitals | `\mathbf{Q}`, `\mathbf{Z}`; on063 `\unsure{\mathbf{Z}\|Z}` | The alphabet of Z in the group on063 is doubtful; the Q subscript on037 is `\unsure{\ell\|l}`. |
| Generic-looking handwritten E subscript | `E_{\unsure{\eta\|y}}` | Same loop/descending-stroke family on037–059; eta is the primary reading, but y remains visually possible. |
| Angular operation sign on E, R and invariants | `\unsure{\natural\|\xi}` | Scans041 onward: two angled strokes favour natural; the comparison does not remove all ambiguity. |
| Handwritten D for duality | `D` | Ordinary capital D is used consistently; a calligraphic intention is possible on049. |
| Derived-functor R with a doubled left stem | `\unsure{\mathbb{R}\|\mathbf{R}}` | Scans049 and061; not conflated with the plain representation-ring R on041–043 or the typed module R. |
| Local handwritten characteristic symbol | `\unsure{\chi\|\beta}_x` | Overwritten on053; cleaner unlooped forms on055 and057 favour chi. The uncertainty is retained in every affected occurrence. |
| Weight letter with a loop and descender | `\unsure{\varphi\|\rho}` on049/051; `\unsure{\rho\|\varphi}` on053/055/057; clear `\rho` later | Enlarged comparison finds a leftward loop on049/051 and a cleaner rightward loop on053. The differing first readings preserve that visual difference; no uniform mathematical identity is imposed. |
| Typed characteristic-divisor sign | `\unsure{\chi\|\gamma}` | Scans052–060 and066; the crossed descending stroke favours chi. Distinct from the handwritten local chi/beta ambiguity. |
| Typed theta variant | `\unsure{\vartheta\|\theta}` | Scans038,054,060; the same loop/crossbar form is treated consistently, including the barred and indexed forms on038. |
| Clearly written phi | `\varphi` | Group element on045; typed maps on038/054/060. These are not converted into weight letters. |
| Superscript `i*` on037 | `^{i*}` | Star kept distinct from a prime and an exclamation mark. |
| Exclamation marks in functors | `i_!`, `j^!`, etc. | Exclamation-mark strokes are preserved as such; no automatic prime substitution. |
| Primes | `'` or `\prime` inside a doubt marker | Typed L', A', B', v'; handwritten L' and λ' in063–069. Ambiguous or apparently absent primes remain marked or absent. |
| Dual marks | `\check E`, `E^\vee` | Kept in the positions visible; the check on the right-hand L in053 is not removed to repair the formula. |
| Double quotation marks | two backticks and two apostrophes | Includes the quoted unipotent on039 and niveau on065; no replacement by guillemets. |
| Handwritten class and trace abbreviations | `\operatorname{cl}`, `\operatorname{Tr}` | Typeset as visible abbreviations, without spelling them out. |
| Handwritten Im, Mod, card | `\operatorname{Im}`, `\operatorname{Mod}`, `\operatorname{card}` | Kept as written. |
| Equals-sign shorthand within prose | `\unsure{$=$\|même}`, `\unsure{$=$s\|mêmes}` | Verified on041,047,065,067; the symbol is the primary reading. |
| Plain horizontal connection without a visible head | `\mathrel{\text{---}}` or tikz-cd `no head` | Especially041,047,061; an arrowhead is not supplied from the argument. |
| Repeated plus/minus or small exponent strokes | literal signs, with `\unsure` where needed | The apparent missing second ± on057 and uncertain minus/plus on067 are preserved, not algebraically repaired. |
| Typed short dashes | `-` | Headers, proposition separators and the three cases on048 use the short stroke; TikZ path `--` syntax is unrelated. |
| Pencil numbers at the lower left | `\margin{35}` through `\margin{69}` | Visible sequence is scan minus one; authorship is not established, so these are not silently labelled authorial manuscript pagination. |
| Typed internal headers | literal text, e.g. `6 - 31 -`, `n\textsuperscript{o} 392` | Distinct from scan numbers and from authorial page counts. |
| Blank internal cross-reference slots | `\quad` | No missing reference number is supplied. |
