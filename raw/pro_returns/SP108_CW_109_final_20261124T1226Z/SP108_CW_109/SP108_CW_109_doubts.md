Enlarging the crops exposes the surviving strokes but cannot restore the covered ones. Uncertainty remains in place in the page fragments, with the preferred visible reading first.

Witness C supplies a full draft for every page. It was useful for locating entries and known doubts; each word and state was checked visually. Its readings were corrected where the ink settled a different letter, mark, number, or cancellation extent. Each of the six mapped H entries supplies a description only. Those descriptions offer no independently transcribed words for collation, so the H collation table has its header and no data rows.

The small number of reading changes is not a measure of certainty. The retained doubts, blind readings, and crop adjudications document the limits of this pass. No OCR, external reconstruction, mathematical emendation, or TeX compilation was used.
