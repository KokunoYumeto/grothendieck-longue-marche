# Notation table

This table records the conventions used throughout the package. Alphabet differences are retained when the ink differs: consistency does not mean replacing one text's notation with another's. All 42 pages received a second image audit; recurring forms were compared before freezing.

| Visible form / feature | LaTeX rendering | Scans / cautions |
|---|---|---|
| Ordinary variables and typed capitals | `E`, `S`, `M`, `G`, `A`, `p`, `e` | Not promoted to blackboard bold because of their mathematical role. |
| Projective plane with lowered numeral | `P_2` | 003, 006: the 2 is an index. |
| Doubled integer symbol | `\mathbb Z` | 004, 009, 011, 018–025, 031; doubled diagonal checked on 004. |
| Ordinary typed F versus doubled F | `\mathrm F_3`; `\mathbb F_4` | 020 versus 022: the alphabet difference is visible. |

| Curled structure-sheaf O | `\mathcal O` | Elliptic-curve sheets; distinct from the programme's underlined O. |
