Editorial rendering harness, not part of the diplomatic text.
Uses pdfLaTeX-compatible UTF-8 input and T1 text fonts by default.
No French babel: French language package is unavailable.
ulem when available; otherwise boxed text/math underline fallbacks.
Fallback underlines cannot wrap; text deletions use red editorial brackets and can span paragraphs.
Math deletion uses cancel; inserted and doubtful text has visible markers.
Margin notes print in reading order with a colored editorial label.
Each scan begins on a fresh rendered page; this need not match manuscript pagination.
figure macro is repurposed for the required TikZ drawing wrapper.
diagram reads active ampersands for TikZ; ordinary arrays also supported.
Do not nest an entire diagram inside another capturing macro; mark individual objects instead.
TEXMFDBS/TEXINPUTS and font lookup paths are process-local fallbacks.
Local format/map assets may be selected with MPL_TEX_ASSETS; no setup is run automatically.
