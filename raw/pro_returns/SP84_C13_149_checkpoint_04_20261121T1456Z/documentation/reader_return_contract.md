# Reader return contract
Read only the one assigned page's packet and images, this contract, reader_instructions.md and provided notation. Do not read other pages, other agents' returns or the full source corpus. No OCR, web research or TeX compilation. Do not spawn agents. Your role is first reader, root will inspect crops and write the final page.

Use tools.view_image through functions.exec to LOOK at the full image once for layout, then the two already-made halves once each, then tight enlarged crops as required. Image-only crops may use Pillow. Keep all meaningful ink even if uncertain. Do not silently normalize Greek symbols, accents, abbreviations, deletion state, or primes. H's editorial notes are not source text but may describe source corrections; inspect the image for each.

Make crops under edition/crops/, prefixed with your page e.g. 149_scan005_c01.png. Save original pixel boxes. A crop should show one place, its word/formula and a line around; enlarge with LANCZOS to about 2200–3000 px across and autocontrast. One crop per place in this reading; never recrop a decided place. Reuse a crop spanning a complete formula for its multiple adjacent questions. Every C/H different word and every resolved C mark requires a crop. Every material departure from either witness must have a crop available for root to inspect, even if the halves settled it. Rendering-only syntax changes do not count. Mere added uncertainty without a different reading is in doubts, not changes.

Write edition/reviews/<page>.tex as your proposed complete LaTeX fragment (matching C headers). Write edition/reviews/<page>.json as a UTF-8 JSON object with these fields. All strings may contain literal TeX; avoid unsafe shell interpolation. Prefer Python heredocs or tools.apply_patch.

- scan: integer; reader: your agent name; lines_read: number of actual manuscript lines inspected, including distinct formula rows, not TeX source line count.
- changes: list of objects {id,place,C,H,final,evidence,crop,box,confidence,against_C,against_H,kind,error_category,marked_in_H,mathematical}. id c01 etc; place names manuscript line or display/margin; crop path relative to edition e.g. crops/149_scan005_c01.png; box [x0,y0,x1,y1] original image; confidence high/medium/low; against_C/H booleans for substantive reading/state difference, NOT macro-only differences. kind is one of user's collation kinds (misread word, misread symbol or index, omission, text not on the page, deletion state, insertion or placement, abbreviation expanded or spelling modernised, readable ink left as \\ill{}, drawing or diagram, other). error_category is one of Symbols and indices; Words; Omissions; Drawings and diagrams; Readable ink left as illegible; Insertions put in the wrong place; Struck text; Abbreviations expanded, spelling modernised; Text that is not on the page; Other. marked_in_H boolean. mathematical boolean. Evidence describes actual letters/strokes observed and what is NOT plain. Include every substantive place differing from either witness, even where C is retained. When unsure, explicitly preserve the doubt and confidence.
- decisions: one object for EACH packet marks.tsv row in its order: {id,decision,reading,evidence,crop,box,confidence}. decision first/alternative/other/undecided; reading must match what your page contains. A resolved mark requires a crop with decisive strokes. For undecided use existing crop or 'page'.
- inventory: list {scan,sheet_kind,hand,element,kind,position,first_words_or_objects,transcribed}. Every text paragraph/display/diagram/drawing/marginal note and EVERY separate insertion/deletion gets an element row. Source folio numbers count as text; archive ids can be comments. No invented elements. All transcribed yes only if included in your page.
- notes: English page summary and any mathematical reading decisions, literal slips/doubts, date/folio/title. Reference locations. No claims of proof when merely transcribing. Use stable statement ids such as S005.1 where actual reasoning occurs.
- checks: list {statement_id,date,who,type,outcome} ONLY for actual mathematical checks or background used. Reading a claim is not a check. Empty list is valid. Do not invent your effort level; identify model as GPT-6 Astra Pro, effort not exposed, run SP84_C13_149.
- hand: list {habit,pages,consistency,misread}; local verified habits only. Give failures and limits.
- notation: list {written,rendering,meaning,evidence}; recurring notation locally observed.
- abbreviations: list {form,expansion,place} (expansion only here, never in transcription).
- doubts: list {place,reading,alternatives,confidence,reason}.
- audit_boxes: list {box,kind,x0,y0,x1,y1,reading}. Unique ids b01 etc; boxes must include every insertion, every margin note, every struck passage, every formula with a doubt mark in C or your page (whole formula), every handwritten number, every C/H different word, and every low/medium-confidence departure from C. Reading contains ONLY transcribed source within that specific box in our macros; be precise about which adjacent context is included, favor tight boundaries with enough surrounding context. This list is preparation only, not the independent reading. Root will freeze it before sending to another reader. Since all pages are handwritten, “every number written by pen” includes folios, formula numbers, numeral indices and inline digits, but nearby numbers in one whole formula may share a box.
- diff_coverage: list of {row,classification,change_id,reason} for each row of packet differences.tsv (1-based excluding header). classification material / macro-only / editorial-only / reading-agrees. This ensures no supplied difference is forgotten. Do not count metadata/macro wrappers as manuscript text.

Return a concise summary to root when these files are ready, naming crop files needing particular attention. Do not write final aggregate files or progress.log; root owns those. Do not save separate library items; root handles the complete requested checkpoint and final ZIP.
