## Self-contained restoration

All three replay helpers resolve source, input and payload paths relative to the extracted archive. They hash the retained files before use. Every project header is included. If a recorded native executable is unavailable, nonexecutable or has the wrong hash, the helper compiles the included C++17 source using the explicit source include directory and standard GMP/zlib dependencies. No live process, scratch capture, missing external file or network retrieval is required.

The main helper is code/pbc_restore_trace_replay.py. The primary-prefix helper is code/pbc_restore_primary_replay.py. The direct quotient helper is code/pbc_restore_full_source_replay.py. The generic transformation entries specify their exact restore commands and kind=gzip_payload. A newly generated gzip wrapper may differ, but every decoded proof byte, its exact hash and count are preserved; original wrapper sizes and hashes remain recorded.

The main finalizer writes checkpoint12-specific recipes and ledgers only after a complete replay and the complete leaf roundtrip. It also independently checks the entire old GMP prefix against the new immutable capture. The source freeze does not alter any mathematical section or register.
