# The modular two-group: a precise remaining barrier

Status: notes only, unregistered. This is a failure of the current proof method, **not** a counterexample to Task A.5. All-prime normalizers are already covered by A59 because the closure is nilpotent; the fixed-subgroup comparison outside the closure prime is the remaining issue.

Consider the actual finite geometric quotient specified by a generating pair r,s in

\[
M_{4n}=\langle r,s\mid r^{2n}=s^2=1,\ srs^{-1}=r^{n+1}\rangle,
\qquad n\ge4\text{ a power of two}.
\]

The geometric fundamental group of the once-punctured elliptic curve is free profinite of rank two, so this epimorphism defines an actual connected finite geometric Galois cover, descending to a finite number-field extension. No explicit curve equation is presently asserted.

Its commutator is r^(-n)=sigma, the central involution. Thus the actual cusp inertia is I=<sigma> of order two, the cusp count is2n, and Riemann–Hurwitz gives genusn+1. The central quotient has abelian groupC_n×C2 and is an actual elliptic isogeny. Its Jacobian has potential-good supersingular reduction at2. The nilpotent ramified-cover theorem supplies compact type for the full source.

The anti-invariant factor for sigma has dimensionn and a unitalQ(zeta_(2n)) action, so the actual special étale2-divisible Tate space again has rankzero or rankn. The positive alternative is ordinary. The same component DS/RH argument would force all anti-components to be ordinary with genuszero involution quotient. Any component stabilizer cannot contain an element with an order-four power squaring tosigma. Its rotation intersection is therefore{1,sigma}, and the possible stabilizer is at mostV4. The dimension bound permits exactlyn ordinary elliptic components, in one orbit, alongside the old supersingular elliptic contribution.

The crucial distinction from A73 is that the entire generic inertia is only<sigma>. There is no nontrivial subgroup of the rotation group that both moves those elliptic components and fixes every generic cusp. The2n generic cusps can in principle supply the two smoothsigma-fixedpoints on each of then ordinary elliptic components. In that configuration the child subtrees used in A73 need not be unmarked, and the genus count is consistent:

\[
g=n+1=n\text{ ordinary elliptic genera}+1\text{ old elliptic genus}.
\]

This is a permitted combinatorial configuration, not an assertion that it occurs for the actual arithmetic cover. An actual stable-model calculation, another monodromy kernel, or a different arithmetic detection argument is needed to decide these fixed subgroups. In particular no general nilpotent fixed-group theorem follows from A70–A74.

Atn4 this is the order16 modular group, with an actual genus-five Galois cover and eight cusps. Its coefficient2 fixed subgroup is covered by A22, and all normalizers by A59; no conclusion for the full fixed subgroup at coefficient3 is obtained from the current rational-path method. This is not claimed to be the least-degree undecided cover, nor to lie outside every possible future consequence of the existing results.
