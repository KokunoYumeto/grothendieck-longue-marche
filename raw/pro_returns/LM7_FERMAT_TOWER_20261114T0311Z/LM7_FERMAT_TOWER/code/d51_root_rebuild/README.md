# Independent D51 rebuild

From this directory, run `python code/d_cm_class2_moving.py` and `python code/d_class2_diagnostic.py`. Both require only the Python3 standard library and the included immutable D50 JSON. The entire JSON certificates and stdout were compared; only the elapsed-time fields are excluded. The finite base has order1080. The separate arithmetic G3 lift is proved symbolically in the paper.
