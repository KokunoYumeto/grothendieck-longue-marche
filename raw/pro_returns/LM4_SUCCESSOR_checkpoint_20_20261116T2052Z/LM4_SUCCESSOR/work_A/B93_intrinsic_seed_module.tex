\statement{B.93}{Proved}{The actual finite seed module with all residual coefficients has free rank 116 and exactly the four certified source classes}
\label{stmt:B93}
Retain the discrete actual modules of B.91--B.92, identify the two
free factors by $F$, and put
\[
 \Lambda=\mathbb Z[E],\qquad E=R\times R,\qquad
 P=I_{\mathbb Z[R]}\otimes_{\mathbb Z}I_{\mathbb Z[R]}.
\]
Let $c_0,\ldots,c_{63}\in\overline L\subseteq P$ be the $64$
actual common-whisker node columns in the corrected paired marking
specified in the proof. Define the $F$-stable submodule
\begin{equation}\label{eq:B93-seed-module}
 L_{\mathrm{seed}}=
       \sum_{j=0}^{63}\bigl(\Lambda c_j+\Lambda F(c_j)\bigr).
\end{equation}
Thus the coefficients range over the full group ring of the actual
infinite group $E$, not an augmented matrix or a bounded set of words.
There is an exact sequence of $\Lambda$-modules
\begin{equation}\label{eq:B93-free-ranks}
 0\longrightarrow\Lambda^{12}\longrightarrow\Lambda^{128}
     \longrightarrow L_{\mathrm{seed}}\longrightarrow0,
 \qquad L_{\mathrm{seed}}\cong\Lambda^{116}.
\end{equation}
The involution on a free image basis has $56$ exchanged pairs and
four negative fixed summands, after the explicit unit changes below.
Consequently, for the diagonal left $R$-action,
\begin{equation}\label{eq:B93-seed-cohomology}
 \begin{gathered}
 H^1(C_2,L_{\mathrm{seed}})\cong\mathbb F_2[R]^4,
 \qquad H^2(C_2,L_{\mathrm{seed}})=0,\\
 \operatorname{im}\bigl(H^1(C_2,L_{\mathrm{seed}})
                  \longrightarrow H^1(C_2,P)\bigr)
   =J_4:=\sum_{i=1}^4\mathbb F_2[R](\rho_i-1)
   \subseteq J_I.
 \end{gathered}
\end{equation}
Here $\rho_1,\ldots,\rho_4\in I$ are the four actual positive
first-sheet source meridians specified in B.93.4. In particular,
every integral anti-invariant chain in this full $\Lambda$-span
has zero obstruction modulo the actual source ideal $J_I$.

This assertion is intrinsic to $\overline L\subset P$. It admits
the induced equivariant refinement of B.93.5, which gives honest
classes in B.92's $H^2(C_2,Z_2)$ without identifying two differently
marked relation kernels. No exhaustion of the retained-fiber deck
or old-base translates of the node set is claimed. In particular,
the result proves neither $\kappa=0$ for the full module nor the
projected source equality, nonlinear fixed lifting, or a compact
coefficient comparison.

                         H^1(C_2,D)=H^2(C_2,D)=0.
\end{equation}

\emph{B.93.5. Intrinsic anti-chains and an equivariant refinement.}
More generally, an actual finite expression $v\in\overline L$
with $F(v)=-v$ determines a class of $H^1(C_2,\overline L)$.
Its image in $H^1(C_2,P)$ belongs intrinsically to $U$, and
its image modulo $J_I$ belongs to $\operatorname{im}\kappa$.
This needs no equality between relation kernels from different
whisker choices. Merely solving the anti-invariance equation
modulo two would not suffice; $F(v)=-v$ is an integral equation.

Here is an explicit comparison giving a representative in the
equivariant presentation. Write $d_0:P_0\to\overline L$ for
B.92's onto node map and $Z_2=\ker d_0$. Let $C$ be a free
$\Lambda$-module on any finite list of actual common columns
used in $v$, and set
\[
 J(C)=\operatorname{Ind}_{E}^{E\rtimes C_2}C.
\]
Map its two copies to the chosen actual columns and their
$F$-images. With this map $d_C$, put
\[
 P_+=P_0\oplus J(C),\qquad
 d_+(p,q)=d_0(p)+d_C(q),\qquad Z_+=\ker d_+.
\]
Since $d_0$ is onto, projection to the second summand gives
an exact sequence of equivariant modules
\begin{equation}\label{eq:B93-refinement}
 0\longrightarrow Z_2\longrightarrow Z_+
      \longrightarrow J(C)\longrightarrow0.
\end{equation}
The underlying $C_2$-module of $J(C)$ is induced, so
$H^1(C_2,J(C))=H^2(C_2,J(C))=0$. Equivalently, each fixed
two-component vector is a norm and each anti-invariant one a
difference, with no division by two. The exact cohomology
sequence therefore gives the canonical isomorphism
\[
                   H^2(C_2,Z_2)\xrightarrow{\sim}H^2(C_2,Z_+).
\]
Also $H^1(C_2,P_+)$ has the same image $J_I$ in $H^1(C_2,P)$
as $H^1(C_2,P_0)$. The residual map constructed from $P_+$
therefore agrees with B.92's $\kappa$ under this isomorphism,
by naturality of the exact sequences.

If $p\in J(C)$ maps to the integral anti-chain $v$, then
$z=(1+F)p$ is an invariant element of $Z_+$. Its $H^2$ class
maps to $\operatorname{diagTate}(v)$ modulo $J_I$, and the
isomorphism just proved supplies the corresponding original
$Z_2$ class. For $v\in L_{\mathrm{seed}}$, B.93.4 proves
that this value is zero. It does not prove that the $H^2$ class
itself is zero. Likewise, a symmetrization $u-F(u)$ is already
a coboundary and cannot by itself furnish a new diagonal value.
