# Authored component-preview classification

The packager's existing third-party-source exclusion rule for work_DE
PDFs is now restricted to PDFs without a corresponding authored TeX
source. This keeps the new B84 component preview with its actual QA
records and avoids mislabelling it as a third-party source copy.
The explicit earlier component-preview exclusions retain their accurate
supersession reason; all prior archived bytes remain covered by the
version-retention audit. No earlier archive is modified.
