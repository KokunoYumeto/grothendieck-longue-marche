# Reader protocol

Read only the assigned page packet, its images, `/workspace/scratch/3933aa5dedf2/reading_instructions.md`, the preamble, and the current notation table supplied with the assignment. Do not read other pages or other readers' reports. No web research, OCR, text recognition, TeX compilation, or image-generation tool.

Read the original image once for layout, then the two already prepared full-resolution halves once each, carefully line by line. Use `tools.view_image` and emit its result with `image(...)` in functions.exec. Witness agreement is not evidence: see every word/sign in the image. Check each deletion and insertion explicitly. Crop each open place once, and ALWAYS crop words differing between C/H and each C doubt you resolve. Save crops in `work/crops/` as `<page>_<place>.png`; use Pillow, original pixel boxes, LANCZOS to about 2200–3000 px wide, autocontrast (sharpen only if needed). View each crop yourself. Do not recrop a decided place. Retain honest doubt if the ink does not decide. Every substantive departure from C or H needs a report row, including punctuation/abbreviation/underline/deletion/insertion changes; ignore pure wrappers/macros and H editorial prose. Record plain/unclear letters for disputed words, and the decisive strokes for resolved doubts.

Write `work/reports/<page>_draft.tex` and `work/reports/<page>.json`. Do not write `work/pages`, shared tables, or progress.log; the main reader adjudicates and commits them. Use the supplied LaTeX macros only. Your report JSON must have these keys:

- `page`, `cote`, `scan`, `reader`, `line_count` (count manuscript lines incl. display lines and marginal lines; explain if exceptional), `layout`.
- `changes`: array of objects, one per place: `place`, `C`, `H`, `final`, `evidence`, `crop` (relative `crops/...png`, or empty if halves alone settle a nonword issue), `box` ([x0,y0,x1,y1] or null), `confidence` (high/medium/low), `against_C` (bool), `against_H` (bool), `kind` (user's collation category), `marked_in_H` (yes/no), `consequential` (bool). Final reading may retain an unsure macro. Distinguish certainty-only changes from substantive differences with optional `certainty_only`: true.
- `decisions`: every MARKS.tsv entry for your page, in order, objects with `id`, `cote`, `scan`, `decision` (first/alternative/other/undecided), `reading`, `what the ink shows`, `crop`, `confidence`. An unresolved mark can name page; a resolved mark must cite a crop and original box. Include separate doubt notes for struck-out marks not in MARKS.tsv.
- `inventory`: objects with `scan` (full page ID), `sheet_kind`, `hand`, `element` (unique within page), `kind`, `position`, `first_words_or_objects`, `transcribed` (yes). All text blocks/displays/diagrams/drawings/insertions/deletions/margins, top to bottom. Include author page number in inventory.
- `doubts`: objects with `place`, `reading`, `alternatives`, `confidence`, `reason`.
- `notes`: English text on what page says/computes/asks, author's own doubts or slips, any mathematical reason that prompted inspection. A transcription summary is not an independent proof check.
- `check_events`: objects with `statement_id`, `date`, `who`, `type`, `outcome`, only for checks actually done or background actually used. Never invent verification.
- `hand_habits`: objects with `habit`, `places`, `scope`, `witness_errors`; describe only observed local forms, avoid premature universal assertions.
- `notation`: objects with `form`, `meaning_or_use`, `places`.
- `abbreviations`: objects with `form`, `expansion`, `places`.
- `second_boxes`: objects with `box` (B01 etc.), `kind`, `x0`, `y0`, `x1`, `y1`, `reading`. Provide a box for every insertion, margin, struck passage, entire formula containing any C/final doubt, handwritten number (include page no. and numeric formulas), every handwritten word on typescript, every different C/H word, every departure from C with less than high confidence. One box can cover overlapping conditions but keep a tight coherent passage and list all applicable kinds. Reading must be exact LaTeX of the full ink inside that box, including deletion/insertion, independent of surrounding sentence. Do not make second-pass crops yet.

Return a concise report with file paths and unresolved major issues. Do not write to the user or save to Library; root handles those. One assigned page only, then wait.
