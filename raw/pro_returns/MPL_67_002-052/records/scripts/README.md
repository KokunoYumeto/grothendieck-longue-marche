# Procedural script provenance

These files are byte-for-byte copies of the root-level scripts present when this record was made. Save scripts document the first transcription pass or the save operation at their creation time. Later ink-based corrections may already be present in the page files. Do not rerun a save script over an audited or frozen page. The current files in `pages/`, and the frozen hash manifest once created, are the authority for the delivered transcription.
