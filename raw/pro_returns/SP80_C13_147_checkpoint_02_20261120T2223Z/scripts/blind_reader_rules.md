# Independent image-only reading

Read only the assigned page image(s), the supplied box-coordinate TSV, and these generic conventions. Do not inspect any witness, first reading, proposed or final page, report, notation table, previous crop, changes log, or root notes for the assigned page. Do not search the work directory for its text. You did not perform its first reading. Your output must be written before the root compares it with the first reading.

For each box, create a fresh crop from the original page with `crop.py SCAN second_BNN X0 Y0 X1 Y1`. Open and inspect that crop. Read every complete ink item inside the box, including deletions, insertions, accents, punctuation, signs, indices, labels, and numbers. Do not infer omitted text from the mathematics or neighbouring sentences. Do not describe diagrams in prose: encode them. If the box includes small fragments from neighbouring lines, identify those as edge fragments separately in a short auxiliary note rather than inventing complete words. The intended target is the complete passage bounded by the box.

For slanted writing, the crop command accepts an optional final rotation angle. Keep the listed original-coordinate box unchanged and make only this one fresh crop for that box.

No OCR, text recognition, external research, or TeX compilation. Do not consult another agent's reading. Retain genuine uncertainty as `\unsure{reading}` or `\unsure{reading|alternative}`. A struck uncertain passage remains uncertain unless all its letters are visible. `\illegible{n}` is for physically unreadable prose, never a mathematical symbol. Do not add missing punctuation or correct grammar, spelling, an index, or a mathematical slip. Raised abbreviation letters are superscripts. Double quotation marks are two backticks and two apostrophes unless guillemets are drawn.

Conventions: `\deleted{...}`, `\inserted{...}`, `\margin{...}`, `\uline{...}`, `\uuline{...}`, `\unsure{...}`, `\illegible{n}`; standard LaTeX mathematics; `\diagram{\begin{tikzcd}[ampersand replacement=\&] ... \end{tikzcd}}`; `\figure{...}` for a TikZ drawing. Use single literal TeX backslashes in actual strings, not doubled literal backslashes. Do not enclose a paragraph-level diagram in display-math delimiters. Handwritten formula numbers are transcribed explicitly, not generated by an equation counter. Inspect both ends of every connector.

For a vertically turned mathematical label, use TikZ label options, for example `\arrow[d,phantom,"\simeq"{rotate=90,description}]`, or a rotated TikZ node. Keep diagram labels in math mode; use `\text{...}` for prose within them. These are generic syntax conventions, not information about the ink in any assigned box.

Write `edition/second/147_scanNNN_second.tsv`, UTF-8, using Python `csv.writer` with tab delimiter. Columns exactly `box`, `reading`. Preserve box IDs and order. Write the full literal reading of each box, not just the most interesting word. Store comments, uncertainty reasons or edge-fragment observations in `edition/second/147_scanNNN_reader_notes.md`, never inside the transcription field. Send the root the two paths, number of boxes read and any unresolved strokes. Do not edit a first reading or a final page. Do not amend the second TSV after the root has compared it; any later clarification belongs in a separate note.
