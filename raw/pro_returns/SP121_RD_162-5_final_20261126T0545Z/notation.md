# Shared notation

This is an observation table, not a rule for correcting the author's mathematics. Each occurrence must still be checked against its own ink. The current summary is reconciled with the accepted records and completed audits for all 21 supplied scans, 025–031 and 033–046; unresolved local forms remain separately marked.
