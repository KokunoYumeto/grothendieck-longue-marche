# Blind second reading

Read only the assigned original image and its neutral `_boxes.tsv` file. Do not read either witness, any page transcription, `_first.tsv`, the box index, the first reader's report, the notation table, prior crops, or the main reader's notes for this page. Do not search other pages for a proposed reading.

Use `blind_crop.py IMAGE BOXES OUTPUT_DIRECTORY` to create each requested box once. Open and actually inspect every crop; a truncated image output does not count. Rotate a slanted box upright if needed, without changing the prescribed source bounds. Do not use OCR or compile TeX.

Write your independent reading of every box in the already established diplomatic conventions, including inserted and cancelled material, numbers, quotation marks, formulas, and diagrams. Preserve uncertainty. Give complete legible words within the box and do not invent words clipped at its edges. Where a box contains a diagram or drawing, use TikZ/tikz-cd rather than a description.

The neutral conventions are: `\deleted{...}` for crossed-out ink, `\inserted{...}` for additions, `\margin{...}` for marginal text, `\uline{...}` and `\uuline{...}` for single and double underlining, and `\unsure{reading}` or `\unsure{reading|alternative}` for local doubt. Use `\illegible{n}` only for physically unreadable prose, never as a substitute for a mathematical symbol. Doubt inside a cancellation remains unless every letter is plain. Use paired backticks/apostrophes for handwritten double quotation marks, retaining guillemets only if drawn. Set formulas in ordinary LaTeX, diagrams as `\diagram{\begin{tikzcd}...\end{tikzcd}}`, and drawings as `\figure{\begin{tikzpicture}...\end{tikzpicture}}`. Preserve abbreviations, spelling, punctuation, incomplete delimiters and mathematical slips exactly; do not expand or repair them. Authorial page labels may use `\mspage{...}`; pale foliation may use `\margin{...}` without guessing its author.

Write UTF-8 tab-separated `_second.tsv` with exactly the columns `box` and `reading`, using `csv.DictWriter` so multiline readings are properly quoted. Keep the neutral box IDs exactly. Write no first-reading comparison, since those readings are unavailable to you. Report the output path and which image files you actually viewed. Wait for the main reader before taking another page.
