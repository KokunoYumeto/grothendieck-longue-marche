# Shared notation table (kept during the visual transcription)

| Ink / usage | LaTeX | Reading policy |
|---|---|---|
| Underlined Hom | `\underline{\mathrm{Hom}}` | Keep underlining where present; distinguish plain Hom. |
| Bar over T, s, k(s) | `\overline T`, `\bar s`, `\overline{k(s)}` | Preserve each visible bar; mark uncertain scope. |
| Superscript ét. | `^{\mathrm{ét}.}` | Retain period if visible. |
| Star below f | `f_*` | Do not substitute another functor from context. |
| A prime | `'` | Distinguish from a separate exclamation stroke and dot. |
| Double quotation marks | two backticks / two apostrophes | Use guillemets only for visible guillemets. |
| Plain manuscript dash | `-` / `--` in text | Do not supply an arrowhead. |
| Abbreviated tout | `tt` / `tous` as visible | Do not expand in transcription. |
