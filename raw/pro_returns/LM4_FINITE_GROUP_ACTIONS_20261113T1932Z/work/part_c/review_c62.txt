1. Exact source and target maps.

The proof retains the original universal source p_O:X_O->O and the specified
real target F_O. The C43 product homeomorphism identifies this exact target
with the second coordinate on a plane; it is used only as a chart. Every
original based source lift acts on the target by an increasing homeomorphism.
No commutation with the auxiliary product flow is assumed or needed.
The hypothesis is equality of the two real target values. Equality only in a
circle quotient would not give the single separating fiber used below.

2. The excursion and its exact disk.

For a complementary interval (a,b) of the level-zero set, put
A=tilde f_a tilde x, h_r=tilde f_r(tilde f_a)^(-1), and g=h_b.
The identities h_a=1 and B=gA are exact. If the excursion of A lies above
the level c, its induced increasing target map beta_r satisfies
beta_r(c)>c, hence beta_r^(-1)(c)<c. The map beta_b fixes c, so it preserves
both strict sides. Consequently h_r A is strictly above and
g h_r^(-1) A is strictly below for every interior excursion time.
They have endpoints A,B and B,A, respectively.

The triangle a<=v<=u<=b maps by
h_u h_v^(-1) A = tilde f_u (tilde f_v)^(-1) tilde f_a tilde x.
Its v=a edge is the first path, its u=b edge is the second path in the stated
orientation, and its diagonal is the constant A. These are the actual
boundary maps of one continuous disk, with no relabelled or newly chosen
source lift. Cancellation proves the displayed three-letter formula.

3. Winding without a simplicity assumption.

For an interior point q of the fiber segment from A to B, the two strict
half-planes are convex in the actual product chart. Each of the two paths
can be homotoped, with endpoints fixed, to a polygonal arc in its own
strict half-plane. At interior parameters, straight interpolation stays
strictly on that side and avoids q. The endpoints also avoid q.
The resulting polygonal loop is a diamond containing every such q and
has winding plus or minus one. Thus the original triangle boundary has
the same nonzero winding, even if its original constituent paths intersect
themselves. A disk missing q would give a null-homotopy in the punctured
plane, which contradicts that winding. Both segment endpoints are already
triangle-vertex images. The degenerate A=B case is immediate.

4. The compact zero set and all endpoint values.

The zero set Z is closed in [s,t] and contains s,t, so each complementary
interval has both endpoints in Z. Retaining the horizontal coordinate xi
on Z and linearly filling each gap gives a continuous real function e.
For short gaps, the oscillation bound follows from uniform continuity of
xi; long gaps are finite in number and their linear extensions are
continuous at endpoints. This proves continuity at every accumulation
point of gaps, rather than assuming that Z is a finite union.
The intermediate-value theorem makes the image of e contain the complete
interval between the two original endpoint coordinates. A value attained
on Z is an original prefix image; a value attained in a gap belongs to
that excursion's already covered fiber interval. A zero-level image is
itself the three-word value a=v=u=r. Every excursion triangle has ordered
parameters 0<=a<=v<=u<=1. This proves the full source inclusion.

5. Original deck labels and the inverse path.

The projection equation p_O tilde f_r=f_r p_O also holds for inverses,
so the projected word is exactly f_u f_v^(-1) f_a(x).
Based lifts commute with each original source deck transformation:
the deck-valued commutator is a continuous path starting at the identity.
The retained equation F_O delta=F_O+eta_O(delta) translates both endpoints,
the entire single fiber, and every source word by the same deck label.
It does not identify different real levels. The same reasoning applies
to the actual path of inverse lifts, giving the exact inverse word
f_u^(-1) f_v f_a^(-1). No assertion about an auxiliary chosen inverse
family or a new covering label enters the proof.

6. Uniformity over varying orbits and arbitrary frontiers.

The ordered parameter simplex is compact, and
W((a,v,u),y)=f_u f_v^(-1) f_a(y)
is one jointly continuous ambient map. For x_n->x, the set consisting of
all x_n and x is compact. Its product with the parameter simplex has
compact W-image, containing every projected fiber interval, regardless of
which open orbit or actual quotient was used to obtain it.
Uniform continuity gives
sup_lambda |W(lambda,x_n)-W(lambda,x)|->0.
This proves the distance estimate to the fixed compact set W_3(x), and
also excludes ambient escape. Every value of W_3(x) belongs to the actual
G-orbit of x. Thus every accumulation point lies in that same orbit, not
merely its closure. If x is G-fixed, W_3(x)={x}, proving uniform shrinking
of the whole interval. The inverse-family estimate is identical.

7. Scope and metadata.

The claim resolves the remote nonopen-limit and escape possibilities left
by C61 for these equal-real-level intervals. It proves the complete
fixed-frontier estimate. At a nonfixed limiting orbit, W_3(x) can contain
several points, so the proof does not yet select a prescribed median or
exponential boundary value and does not construct a moving-quotient lift.
Both the proof and metadata retain these two remaining tasks explicitly.
No computation or new external theorem is needed for this exact
topological disk argument.
