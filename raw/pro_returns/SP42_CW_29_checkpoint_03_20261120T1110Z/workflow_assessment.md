## Execution observations (updated as work proceeds)

Every reading uses a fresh independent agent. The page-specific notation snapshots issued to the readers are retained in `reader_input_notation/`; changes in later notation do not rewrite earlier snapshots. The original full-page and half-page images never enter the main reader’s view. Main decisions cite the evidence crops actually examined, including retained unsuccessful crops where relevant.

Scan 003 exposed three useful kinds of disagreement: a repeated typed letter miscounted by one reader, an overstrike noticed by only one reader, and hand-added state details listed in an inventory but absent from the reading. Agreement among the other readers was not used to overrule the visible strokes. Correction order and ambiguous alphabets remain uncertain where the image does not settle them.

Readers' original returns remain intact, including rejected readings and feedback. Main decisions can therefore be compared with what each reader actually reported. Counts exclude editorial emphasis, macro syntax, ordinary line wrapping, and equivalent spacing. H uncertainty flags are distinguished from H editorial comments. The supplied preamble is available in each subsequent reader packet; only the first packet omitted it, as the original reports disclose.

Scan 005 added another counterexample to majority agreement: one reader found a clear detached comma that both other readers and C omitted. Main inspection confirmed it. The same page shows why differences in uncertainty should be counted explicitly: resolving same changes C’s doubt encoding even though its first candidate was already correct. The final record distinguishes those decisions from ordinary letter substitutions. Faint marks whose punctuation function remains unclear are retained locally with low confidence.
