# Limited mathematical check during scan 009 reading

The page’s mention of connected non-Galois étale coverings even with D=0 has an elementary example: Spec Q(∛2) over Spec Q, with empty divisor. The cubic T³−2 has no rational root (the only possible integer roots are ±1 and ±2), hence it is irreducible. Its derivative 3T² has no common root with it, so the extension is separable. It is a field extension, so the source spectrum is connected. The real field Q(∛2) does not contain the two nonreal roots of T³−2 and therefore is not normal, hence not Galois. Using the standard finite-field-extension/separable/étale criterion, this gives a connected finite étale non-Galois cover with empty divisor.
