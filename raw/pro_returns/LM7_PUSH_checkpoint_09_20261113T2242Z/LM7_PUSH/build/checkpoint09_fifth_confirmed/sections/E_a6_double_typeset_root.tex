\subsection{The central double cover of \texorpdfstring{$A_6$}{A6} and its exact signed common source}

\begin{statement}{E.63}{Proved}{The entire binary cover fibre retains the signed, triple-cover and uniform boundary system}
Let $U_2=\operatorname{SL}_2(\mathbf F_9)$ with the specified
central map to the retained $A_6$. All $212$ free epikernels

\[
 X_2\twoheadrightarrow G,\qquad
 K_2=\ker(X_2\to G)\simeq\mathbf F_2^{128}.
 \tag{E.63.1}
\]
There is a specified signed quotient of the old
$\mathcal Q_{30}$ map:
\[
 \begin{gathered}
 \widetilde q_{30}:B\twoheadrightarrow\widetilde{\mathcal Q}_{30},
 \qquad |\widetilde{\mathcal Q}_{30}|=9331200000,\\
 \widetilde q_{30}(F)
   =\mathcal U\times(\mathbf Z/30)^2,\qquad
 \mathcal U=\operatorname{SL}_2(\mathbf F_5)^3,\\
 \widetilde{\mathcal Q}_{30}\twoheadrightarrow\mathcal Q_{30},
 \qquad\ker=\mathbf F_2^3.
 \end{gathered}
 \tag{E.63.2}
\]

Both $X_2$ and $G_L$ map onto this quotient. Put
\[
 \begin{gathered}

                              \widetilde{\mathcal Q}_{30},
 \qquad |\mathcal B_*|=8|G|,\\
 X_2\twoheadrightarrow\mathcal B_*,\qquad
 K_*:=\ker(X_2\to\mathcal B_*)\simeq\mathbf F_2^{125},\\

      =X_2\times_{\widetilde{\mathcal Q}_{30}}G_L

 \tag{E.63.3}
\]
The map $J\to\mathcal B_*$ uses its actual $G$ coordinate
and its $G_L\to\widetilde{\mathcal Q}_{30}$ coordinate.
These equations identify the entire common source through
the specified maps.

\[
 \begin{gathered}

 \tag{E.63.6}
