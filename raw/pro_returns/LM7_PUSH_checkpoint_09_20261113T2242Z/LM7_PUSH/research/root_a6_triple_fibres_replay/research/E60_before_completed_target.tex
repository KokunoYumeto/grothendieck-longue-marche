$\mathcal B_0\to G$ is the literal quaternion group $Q_8$.

\[

 \end{gathered}

\]

Let $\widetilde{\mathcal R}_1$ be the full preimage in $J_U$

The exact closed source images are
\[

Every one of the $864$ finite E.54 points, at every retained

\[

 \tag{E.60.6}
\]
The analogous assertion holds for the full inverse system.
Every source fibre over a fixed old value has all $3^{79}$
new $F'$ values available to the correcting subgroup in
\textup{(E.60.5)}. The proof selects the required Galois value
from this complete image; it does not replace this fibre by
one preselected representative.

The corrected word has the same six $T_U$ values as the same

\end{statement}
