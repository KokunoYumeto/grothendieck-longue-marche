SUPPORTING RECORDS

records/ contains the original pre-context observations, audit notes,
post-freeze source checks, context searches, mathematical diagnostics,
note indexes, coverage and integrity reports, and reproducible scripts.

technical_checks/ contains compilation diagnostics and a syntax-checking
preamble/script. These are technical aids, not a diplomatic facsimile layout.
The requested custom state macros are intentionally not defined in the
transcription fragment itself. A receiving LaTeX document must define them
and load the ordinary mathematics and TikZ/tikz-cd packages it uses.

The supplied scans and context archives, downloaded literature PDFs/images,
compiled PDFs, caches, and LaTeX build formats are excluded. Context searches
retain exact matching lines and input hashes as evidence of the searches,
not as a replacement for the supplied source files.

CHECKS

From the extracted directory, the principal structural/hash checks are:
    python records/validate_package.py
    python records/final_quality_check.py

Research search/assembly scripts expect the original supplied context to be
available separately; their command-line options and recorded input paths
identify it. Some earlier compilation logs preserve original workspace paths.

All 46 page fragments and the combined transcription were frozen before any
context was opened. Research reading questions, bibliographic differences,
and mathematical corrections appear only in the notes. Mechanical compilation
and hash checks do not eliminate the explicitly recorded reading uncertainties.
