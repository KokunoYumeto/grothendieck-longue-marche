# Notation table — maintained from scan 133

| Ink / recurring usage | LaTeX convention | Caution |
|---|---|---|
| One underline; two underlines | `\uline{…}`; `\uuline{…}` | Both are retained where distinguishable. |
| Underlined Pic and underlined group letters | `\uline{\mathrm{Pic}}`, `\uuline{\mathrm{Pic}}`, `\uuline{N}` | Number of lines follows each occurrence; uncertain alphabets remain marked. |
| Double quotation marks | two backticks and two apostrophes | Guillemets only when drawn. |
| Plain connecting stroke / arrow | `-` or `\text{---}` / `\longrightarrow` | Do not supply a missing arrowhead. |
| Authorial question mark | `?` | Kept in its position, distinct from editorial doubt macros. |
| Superscript prime / exclamation mark | `'` / `^!` | Inspect each occurrence, never normalize one to the other. |
