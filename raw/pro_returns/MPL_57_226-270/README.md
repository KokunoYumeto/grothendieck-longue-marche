# MPL_57_226–270

Complete diplomatic transcription and research dossier for the 43 supplied scan pages of Montpellier cote 57, scans 226–270, omitting the supplied blanks 232 and 247.

## Main files

| File | Contents |
|---|---|
| `MPL_57_226-270_transcription.tex` | Combined frozen LaTeX fragment, in scan order; no preamble |
| `pages/` | One frozen LaTeX fragment per scan |
| `MPL_57_226-270_doubts.md` | Reconciled notation table, reading doubts, abbreviation glossary, and legibility assessment |
| `MPL_57_226-270_inventory.csv` | 669 inventoried elements, every row marked transcribed |
| `MPL_57_226-270_notes.md` | Final research synthesis: 83 numbered notes, the two planning questions, authorial uncertainty, titles and pagination, source/status index, and proof boundaries |
| `progress.log` | UTC page-completion and audit times, freeze hashes, context-opening boundary, checkpoint and validation records |
| `records/` | Audit history, supporting research, per-note context searches, analytic-module proof, validation, and workflow scripts |

The combined fragment uses the custom markup requested in the task and standard mathematical/TikZ markup. It is intended for the user's existing macro definitions, not as a standalone TeX document. Structural checks passed; a complete rendered compilation was unavailable because the execution environment lacked the required format/package support.

## Evidence and versions

All manuscript images were read by the primary reader in a single transcription stream, with a second visual audit before the freeze. Context research began only after the frozen transcription had been recorded. The final SHA-256 check confirms that all 43 page files and their combined fragment remained unchanged during research.

The final `notes.md` file is the research synthesis. Other reports in `records/` document working stages and may contain tentative readings, earlier proof questions, or recommendations subsequently resolved in that synthesis. `pre_context_observations.md`, the earlier doubts copy, and the audit diff are historical records, not alternative final transcriptions. Supplied research context is explicitly treated as unreviewed unless its register states otherwise.

The scripts are retained as work records. In particular, page-writing, notation-consolidation, and freeze helpers must not be rerun on the frozen text. Read-only hash and archive checks are distinct from those writing operations.

Original attachments, manuscript images, supplied context sources, and temporary external-PDF renderings are excluded from this archive.
