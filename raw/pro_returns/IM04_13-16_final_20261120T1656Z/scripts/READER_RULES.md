# Page reader instructions

Work only on your currently assigned page, its image, and its correction rows. Do not read the full corrections table or any other page. The original sources are immutable. No OCR, text-recognition software, PDF text layer, or online research. Inspect the JPG visually with view_image; create and inspect a tight enlarged, contrast-raised crop for each relevant place. The common crop script is deliverable/scripts/crop_scan.py. Name crops `<page>_<id>_<place>.jpg` in deliverable/crops/; it records a .crop.json alongside. Use width around 2800 (or 2400–3600), contrast around 1.25–1.5. For multiple places in one row, make separate crops.

Decisions: (a) transcription misreading: change only the row's place to what ink shows, in existing macros; (b) author's own slip or proposed mathematical refinement: preserve the ink and record written/intended readings in note; (c) already as requested: no change; (d) asserted phrase not on this page, including metadata/classification absent from page: no change, record location if known from supplied material. For every flagged, open, unsorted, second-model, unchecked or text-disagreeing row decide by ink. Human Michel Hua checks are to be applied unless ink plainly contradicts them. If ink cannot decide, put an explicit \\unsure{reading|alternative} at that exact place, and explain uncertainty. Do not infer ink solely from mathematical plausibility.

Diplomatic conventions: preserve spelling, accents, abbreviations, slips, whitespace and all other unrelated contents exactly. \\deleted{...} = struck; \\inserted{...} = insertion; \\margin{...} = margin; \\unsure{reading|alternative} = doubt; \\illegible{n}; diagrams remain tikz-cd. The watermark EXTRA STRONG and specks are not ink. Read source/PREAMBLE.tex for all macros.

Write your result to deliverable/reviews/<page>.json and candidate to deliverable/reviews/<page>.candidate.tex. JSON shape:
{"page":"14_scan003","reader":"reader_1","rows":[{"id":"L...","decision":"a|b|c|d","find":"EXACT unique original span (a only)","replace":"the same span corrected (a only)","what_the_ink_shows":"specific visible strokes and readings, citing crops/<file>.jpg","confidence":"high|medium|low","note":"For b: what is written and what meant; for d: absence/location; for uncertainty: residual issue. May include concise reasoning for a/c.","crops":["crops/<file>.jpg"],"event_type":"used and rechecked in this run","event_outcome":"Accurately describe visual collation and any mathematical check actually done. Never call merely reading a claim a proof check."}]}

Use find/replace empty strings for b,c,d. For a, the find must occur exactly once in the original page. One row may cover separated places; its replace must leave everything between those places unchanged. If rows' spans overlap, each row's replacement contains ONLY its own changes; the candidate contains their combined minimal edits. Duplicate rows asking the identical edit can record the same original span and replacement, applied once. Do not add undocumented edits.

If uncertain, propose a doubt-marked transcription instead of an unmarked guess; tell the main reader precisely what remains unresolved. Report concise decisions, exact edits and crop paths to main. Main alone writes edited_pages, placements.tsv, notes, CHECK_EVENTS.tsv, progress.log. Do not modify those. Do not spawn other agents. The runtime identifies the model as GPT-6 Astra Pro; reasoning effort numeric level is not exposed, so do not invent one. The main reader will review the returned page and settle every row. Return after one page; wait for the next assigned page.

All original .tex files use CRLF. Preserve bytes outside each edit: use read_bytes().decode("utf-8") and write_bytes(text.encode("utf-8")); multiline find/replace retains \r\n.
