### Counting and scope

The category table above assigns each substantive apparatus row one primary kind even when a place also involves another kind. A row differing from both witnesses is counted once in that table and once against each witness in the changes totals. Certainty-only resolutions are listed in the doubts file and excluded from the substantive counts. Related indices or drawing components sometimes occupy one explicitly described place; the category counts therefore do not equal the number of changed characters or strokes. No extrapolation to other folders is warranted.
