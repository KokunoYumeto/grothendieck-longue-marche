# Notation table

| Handwritten sign or usage | LaTeX transcription | Notes |
|---|---|---|
| Double quotation marks | two backticks / two apostrophes | Use guillemets only when visibly drawn. |
| Prime and exclamation-mark exponents | `'` / `^!` | Distinguish against the ink on each occurrence. |
| Typewritten doubled D | `\mathbb{D}` | Distinct from a single underlined D; scans 47–48. |
| Typewritten underlined E, t, O, Z, Q and Lie | `\underline{E}`, etc. | Preserve the underlining; do not silently substitute script or bold. |
| Typewritten composite asterisk | `*` | Overtyped star in crystalline/duality formulas; distinct from handwritten vee. |
| Added V-shaped dual sign | `\vee` inside `\inserted` | Mark doubt when a proofreading tick is also possible. |
| Rounded crossed theta in blue exercise typescript | `\vartheta` | Scans 50 and 52 belong to the same exercise sequence. |
| Banach-exercise Greek variables | `\gamma`, `\eta`, `\delta`, `\zeta`, `\lambda`, `\mu`, `\nu` | Read letters and bounds independently; retain surprising formulas. |
| Typewritten small round subscript | `\unsure{o|0}` when unresolved | M/A subscripts in black typescript; numerical zero in blue exercise typescript is clearer. |
| Long diagonal cancellation across reused exercises | `\deleted{...}` around body | Printed page/header numbers retained separately. |
| Long descending crossed Euler-characteristic sign | `\chi` | Scans 56 onward; compact-support mark is a lowered exclamation mark, `\chi_!`. Cover 55 retained as uncertain until comparative audit. |
| Curved capital for classes of spaces | `\mathcal{E}` | Subscripts `\chi` and `\chi!` in handwritten Euler-characteristic pages. |
| Real-number letter | `R` or `\mathbb{R}` | Single and distinctly doubled stems are retained as seen; ambiguous overwrites carry doubt marks. |
| Ditto marks above two lower formulas | `\overset{\text{''}}{...}` | Scan 58; not silently expanded into another equality. |
