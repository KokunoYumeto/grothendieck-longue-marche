# MPL 72, scans 035–081

This archive contains the complete diplomatic transcription and post-freeze research for the 47 supplied scans.

## Main deliverables

- **MPL_72_035-081_transcription.tex** — all 47 pages in order, as one LaTeX fragment with no preamble.
- **pages/** — the 47 individual page fragments.
- **MPL_72_035-081_doubts.md** — notation table, uncertain readings, abbreviations, and legibility assessment.
- **MPL_72_035-081_inventory.csv** — 1,052 inventoried elements in the requested eight-column format.
- **MPL_72_035-081_notes.md** — the complete English research report, including short source-linked items, the definition and B5 comparison, all enumeration catalogues, standing questions, proofs, counterexamples, B12's explicit split construction, sources and reproduction instructions.
- **progress.log** — ordered completion and second-reading records, the freeze and context-opening timestamps, 48 frozen SHA-256 values, and final preservation verification.

## Supporting material

The research directory contains every reproducible calculation, CSV/JSON output, context-search audit, and component research text. The records directory retains per-page work records. The scripts directory contains mechanical validators, the notes assembler and the historical preparation tools; reproduction commands are collected in research/reproducibility.md.

The original scans, supplied input archives and context source files are excluded. Per-note source references name those supplied materials explicitly. The returned LaTeX is the requested custom-macro fragment; validation was static and did not produce a compiled preview.
