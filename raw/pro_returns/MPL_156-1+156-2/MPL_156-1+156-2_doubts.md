# Notation table

This table records the conventions used across the complete package. Recurring signs were compared during the page audits and in a final cross-page pass before the transcription was frozen; a genuine change of notation is retained, and unresolved visual alternatives remain marked in place.

| Manuscript sign or convention | LaTeX transcription and audit decision |
|---|---|
| Printed roman text | Standard LaTeX text; printed sans-serif cover in \textsf{…}. |
| Handwritten double quotation marks | ``…''; guillemets only if actually drawn. |
| Underline / double underline | \uline{…} / \uuline{…}. |
| Set of lieux, handwritten looped capital | $L$ in the abstract segment axioms of 156-1; $\mathcal L$ for the more fully looped collection of lieux of a ficelle in 156-2 scans 007, 010 and 012. These are visual alphabet choices, not a claim that every cursive capital L belongs to a distinct mathematical alphabet. |
| Relation/inclusion | $R\subset L\times L$; preserve the actual inequality or inclusion. |
| Circled item number | \textcircled{n}. |
| Whole-block diagonal cancellation | \deleted{…} enclosing the affected text; individual cancellations retained inside. |
| Endpoint set of a segment | $\delta I$; initial symbol resembles a cursive delta; distinguish from any later boundary notation. |
| Segment's set of lieux | $\tilde I$; tilde confirmed in second visual audit, including the earliest cancelled definition. |
| Form/model symbol with curled crossing strokes | $\mathcal X$. |
| Power-set letter with outlined strokes | $\mathcal P$; alphabet marked uncertain where not decisive. |
| Tilde over segment letter | $\tilde I$; compared with bars and circles throughout both readings. Later bare $I$ is retained where actually written. |
| Interior of segment | $\tilde I^\circ$; later bare $I^\circ$ when the support is identified with the segment. |
| Regular / singular lieux | $L_r$, $L_s$. |
| Power set | $\mathcal P(L)$; two-element subsets $\mathcal P_2(L)$. |
| Plain mapping stroke without arrowhead | $I-\tilde I$ where the manuscript has a dash. |
| Interior written with tilde and small upper circle | $\tilde I^\circ$ (not a prime or an exclamation mark). |
| Uniqueness quantifier | $\exists!$; one upright stroke following the quantifier. |
| Indices in segment notation | $I_{x,z}$ and $I_{y,z}$; lower-case z can resemble 2. |
| Finite subset sign on scan 005 | $\Phi$; earlier point-like use marked $\unsure{\Phi&#124;\varphi}$. |

| Axiom / corollary labels | $F_1)$, $F_2)$; preserve Cor. versus Cor without adding punctuation. |
| Ditto line | \rule{…}{0.4pt} for a long horizontal repetition mark; do not expand omitted words. |

| Two-element quotients in the orientation discussion | $\omega_S$, $\omega_L$, $\underline{\omega}$; the common orientation set has a separate underline. |
| Order letter used in the orientation conditions | $o$, $o_I$, $o_J$ (first occurrence marked against $\sigma_I$). |
| Elementary relation labels circled in the manuscript | \textcircled{a}, \textcircled{b}, including relation subscripts. |
| Branch determined by an incident segment | $\beta(I,x)$. |
| Membership annotation written vertically | x above \rotatebox{-90}{$\in$} above \delta I; the rotation follows the ink (156-1 scan 017). |
| Orientation quotient with an underline | $\underline{\omega}$; element $\omega\in\underline{\omega}$. The three stand-alone occurrences in 156-1 scan 016 and the quotient/element distinction in scan 018 were compared; $\omega_S$ and $\omega_L$ remain un-underlined. |
| Origin and terminal-end abbreviations | $\operatorname{or}(I)$ and $\operatorname{ex}(I)$. |
| Definition equivalence | \overset{\mathrm{def}}{\Longleftrightarrow} |

# Legibility and limits

All 46 whole-page scans and both supplied overlapping halves were read visually by the same transcriber, in the specified order; no OCR was used. Every page received a second visual audit before the context archive was opened. The principal running text and most displays are reasonably legible, but this remains a difficult diplomatic reading, not a claim of error-free decipherment.

The least secure material is small rotated marginal writing, multi-layer corrections, and heavily cancelled drafts: especially 156-1 scans 002, 005–007, 023 and 026, and 156-2 scans 002, 005, 007, 010, 011 and 018. In ambiguous corrections, the visible alternatives are retained without asserting an unsupported order of revision. The one physically unreadable span, estimated at two words in the cancelled lower-left margin of 156-2 scan 002, was retained as `\deleted{\illegible{2}}` after enlarged visual attempts; doubtful formula symbols instead receive proposed readings under `\unsure`.

The 44 manuscript sheets each show two low-contrast paper legends, recorded as doubtful `EXTRA STRONG`, with reversal and rotation preserved; these 88 nonmathematical occurrences account for a substantial part of the uncertainty count. The two institutional cover scans are also transcribed. TikZ drawings preserve topology, relative placement, strokes and visible labels as closely as the available images permit, but they are approximations of hand-drawn geometry; diagram-arrow and plain-stroke distinctions remain explicit.

Unbalanced punctuation, unfinished clauses, surprising equalities or quantifiers, differing notations and explicit retractions have not been repaired from mathematical expectations. Any mathematical proposal or possible correction belongs only in the separate research notes. The exact uncertainty index above makes small doubtful items searchable even when the manuscript-position table groups several such items together.
