## Proof gates checked independently of finite computation

1. Actual curve-to-elliptic map and duplication, actual D_(2m) deck action, four exact cusp indices m/2.
2. Nilpotent ramified-cover theorem supplies only compact type. All automorphisms and endomorphisms are defined after a finite extension, and local automorphisms fix the coefficient DVR.
3. The anti-invariant factor has a unital Q(zeta_m) action, so its actual special étale 2-divisible Tate space has dimension0 or phi(m). The positive case is ordinary.
4. Exchanged positive-genus components are impossible, while components on which sigma acts trivially contribute only to the old factor. For nontrivial components, smooth-curve DS/RH force a genus-zero quotient and minimal different.
5. Ordinary curves have no cyclic4 stabilizer. An order-four root of a hyperelliptic involution necessarily fixes a point over the unique fixed point on P1, so is excluded.
6. Primitive cyclic action forces exactly m/2 ordinary elliptic components in one orbit. A smooth sigma-fixed point lifts by the finite-flat Weierstrass argument to a generic cusp, which is individually mu-fixed; it therefore cannot lie on this nontrivial orbit.
7. The second sigma-fixed point of each elliptic component is a child node. Its unmarked descendant subtree contains positive genus by marked stability. Equal-depth vertices give disjoint subtrees and force genus at leastm, contradictingm−1.
8. Four displayed principal divisors give actual m-primary cusp differences. I=<r²> is the normal Frattini subgroup; HI=G forces an odd rotation and a reflection in H, hence H=G. Norms of functions push points with residue-degree1, and all intermediates inherit good 2-rank-zero Jacobians.
9. A41/A42 give actual all-prime fixed subgroups; A59 supplies all-prime normalizers from the nilpotent closure. No universal TaskA5 theorem or arbitrary dihedral-cover classification is claimed.
