# Notation table — maintained from scan 033

| Manuscript sign | LaTeX | Reading policy / occurrences |
|---|---|---|
| Position set, open capital C | `C` | Distinguish the similarly formed winning-set G by its terminal stroke. |
| Winning and losing sets | `G`, `P` | Cursive capital G is often nearly open C. |
| Null set label | `N` | Ordinary capital, not silently calligraphic. |
| Subscript round zero | `C_0` | Preserve subscript; not the letter o. |
| Star or cross superscript | `G^*`, `P^*` with doubt where needed | Scan 033: the strokes are not entirely decisive. |
| Hatted player map | `\hat\alpha` | Scan 033; keep doubtful until comparison across later pages. |
| Player letter and opposite player | `j`, `\bar j` | Descender can look like y; scan 033. |
| Player-indexed subsets | `G(j)`, `\hat C(j)` | Retain parentheses. |
| Successor sets | `R(x)` | Inclusion vs membership checked locally. |
| Set complement stroke | `\setminus` | Backslash drawn, not minus. |
| Empty set, slashed oval | `\varnothing` | Do not transcribe as digit zero. |
| Double quotes, when encountered | two backticks / two apostrophes | Use guillemets only when visibly written. |
