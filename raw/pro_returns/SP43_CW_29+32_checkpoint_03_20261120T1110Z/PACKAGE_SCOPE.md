# Package scope

The package contains the consolidated deliverables, independent reader returns, reader and main-reader crops and their crop records, decision records, brief history, notation snapshots, scripts, check events, and progress documentation.

The supplied archive ZIP, supplied prompt, source scans and halves, witness files, source context, and the unchanged supplied PREAMBLE.tex are inputs and are excluded. The exact preamble used is the PREAMBLE.tex in each supplied Codex folder; its identity is recorded in the source provenance. Reader bundles can be reconstructed from the attached archive using scripts/rebuild_inputs.py; see RESTORE.md. The historical setup script is retained as documentation and must not be rerun over restored records.

The files in pages/ and the combined transcription are the consolidated text. reading.tex under readers/ retains each independent candidate, including rejected readings; it is evidence of the work, not an additional final transcription. Local crop references in the decision tables are relative to the package root. All earlier checkpoints remain separately saved; no checkpoint ZIP is nested in another ZIP.
