\subsection*{Solvable source images and the actual affine stabilizer}
\statement{B.158}{Proved}{Solvable source heads cannot be cofinal, while a solvable Birman target alone gives no such obstruction}
\label{stmt:B158}
The actual B.75 source has a specified epimorphism to \(A_5\).
No finite solvable source image has kernel refining its kernel.
For an arbitrary characteristic finite Birman quotient, the
correct finite object is an affine action, and B.75 requires
its identity-point stabilizer, rather than only its homomorphism
kernel, to refine each prescribed source neighborhood.

\begin{proof}
\emph{B.158.1. The specified nonsolvable quotient.}
In the actual based presentation set
\[
 \pi(e)=(1\,2)(3\,4),\qquad
 \pi(a_0)=(1\,3\,5),\qquad
 \pi(c_1)=\pi(c_2)=1.
\]
The sole relation \(e^2=1\) is respected. With rightmost
permutations applied first,
\[
 \pi(ea_0)=(1\,4\,3\,5\,2).
\]
The image lies in \(A_5\) and contains elements of orders two,
three and five. Its order is therefore divisible by thirty and
divides sixty. An order-thirty image would be an index-two
subgroup of \(A_5\). This is impossible: the three-cycles
generate \(A_5\), and every map from \(A_5\) to \(C_2\) kills
each of them. The image is consequently all of \(A_5\).
Let \(U_A=\ker\pi\).

If a finite solvable source image had kernel \(T\subseteq U_A\),
then \(A_5\) would be a quotient of that solvable image. This
contradicts nonsolvability of \(A_5\). Finite products and
subgroups preserve solvability, so the same argument excludes
cofinality of any topology generated solely by finite solvable
\emph{source} images.

\emph{B.158.2. The actual affine map and its zero test.}
Let \(N_0\) be characteristic and finite index in the actual
\(N=B_4(S_{0,4})\), and put \(Q=N/N_0\). Conjugation by
\(G_V\) induces \(\alpha:G_V\to\operatorname{Aut}(Q)\).
The actual crossed map satisfies
\[
 \delta_Q(gh)=\delta_Q(g)\alpha_g(\delta_Q(h)).
\]
It therefore defines the genuine finite-image homomorphism
\[
 \Psi_Q(g)=(\delta_Q(g),\alpha_g)
       \in Q\rtimes\operatorname{Aut}(Q).
\]
The associated affine action sends
\(x\mapsto\delta_Q(g)\alpha_g(x)\). Thus
\[
 \delta_Q(g)=1
 \quad\Longleftrightarrow\quad
 g\in\operatorname{Stab}_{G_V}(1).
\]
B.75.6 requires this entire stabilizer to lie in the prescribed
\(U_0\). The inclusion of the smaller \(\ker\Psi_Q\) would
be insufficient. Moreover, a solvable or elementary abelian
\(Q\) can have a nonsolvable automorphism image. Hence the
preceding solvable-source argument does not by itself exclude
abelian, finite \(p\)-group, or solvable Birman targets.

\emph{B.158.3. An abstract detector and the exact realization gate.}
For a finite source quotient \(\pi:G_V\to D\) and a prime
\(p\), let \(V=\mathbb F_p[D]\) with the left regular action.
The explicit map
\[
 c(g)=e_{\pi(g)}-e_1
\]
satisfies \(c(gh)=c(g)+\pi(g)c(h)\) and has zero set exactly
\(\ker\pi\). This is an affine detector, although its
translation group is elementary abelian. It has not thereby
been realized as a quotient of the actual Birman crossed map.

Indeed, a proposed equivariant homomorphism \(\varphi:N\to V\)
with \(\varphi(\delta(g))=c(g)\) factors through
\(H_1(N,\mathbb F_p)\). The vectors \(e_d-e_1\),
\(d\in D\setminus\{1\}\), are linearly independent and span
the augmentation subspace. Such a realization requires
\[
 \dim_{\mathbb F_p}H_1(N,\mathbb F_p)\geq |D|-1.
\]
The left side is finite, because the actual Birman group is
finitely generated. This prevents this particular regular-module
construction from working uniformly for source quotients of
unbounded order with fixed \(p\). It does not exclude different
detectors, nonabelian targets, or justified subgroup-and-induction
constructions. The actual uniform identity-stabilizer condition
remains a separate problem.
\end{proof}
