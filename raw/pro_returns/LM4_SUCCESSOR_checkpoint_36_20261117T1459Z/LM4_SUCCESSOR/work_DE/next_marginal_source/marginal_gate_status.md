# Exact positive marginal: current source-membership gate

This is research, not a new numbered solution of the residual A5
centralizer problem. The attached LM4 F22 already specifies the positive
marginal as an image of the actual eight-collision source filling kernel.
F23--F33 establish several finite-image and cocycle comparisons; none
settles the full marginal inclusion or the joint interaction kernel.

## Freshly certified data

The exact rational deformation, based transport, square lassos and
Sturm crossings are documented in `positive_marginal_geometry.md` and
the corresponding program/JSON/stdout. The fiber extraction is in
`extract_positive_fiber.py` and `positive_fiber_data.json`. The fiber is
F7 on x1,...,x7. Its filling retains x2,x4,x6 and kills x1,x3,x5,x7.
The image R of the filling kernel is therefore the normal closure of
those four killed generators. The actual marginal image K_m is the
subgroup generated by all eleven old-source-action orbits of the eight
new fiber words nu11,...,nu18; in the completed setting one takes the
closed image of that actual source, rather than assuming a completion
identification for an abstract infinite-rank subgroup.

The extracted based action is literal conjugation. The last-strand
Artin conjugator itself uses the opposite fiber multiplication
convention, which the extraction corrects by inversion. Both inverse
actions and literal source conjugation were checked. The root's separate
analysis in `records/positive_marginal_index_actions.json` finds that
old actions0,3,4 are outer on the retained F3, while the other eight
act literally as the identity there. Thus the peripheral-index action
is alpha_bar(g) times the filled conjugator, not a presumed inner action.

## A finite free-factor identity

The weighted folding program constructs source-word witnesses and then
checks them by direct free substitution. Let C=x7^-1 x6^-1 x5^-1 x4^-1.
There are exact identities in the original fiber:

    x1 = nu16 nu11^-1 nu14 nu18^-1 nu14^-1 nu11 nu16^-1,
    x7 = nu15^-1,
    C x3 C^-1 = nu11^-1.

An explicit word for x5 uses only nu15 and the inverse of old action6
applied to nu17,nu15,nu14,nu16,nu13. In that order call these six
elements z1,...,z6. Then the actual word is

    x5 = z1^-1 z3 z2 z4^-1 z5 z2^-1 z3^-1 z2 z4 z2^-1
         z6^-1
         z2 z4^-1 z2^-1 z3 z2 z5^-1 z4 z2^-1 z3^-1 z1.

This is independently substituted in `extract_free_factor_witness.py`;
the original arrays and exact stdout are retained. Since C does not
involve x3, the assignment y3=C x3 C^-1 and yj=xj for j!=3 is a
literal Nielsen automorphism, with inverse x3=C^-1 y3 C. Consequently
K_m contains all four killed generators y1,y3,y5,y7 of a genuine free
basis extending the same retained generators x2,x4,x6. In particular
the initial four-peripheral free-factor issue can be removed explicitly.

This does not show that K_m is invariant under conjugation by the
retained generators. Nor does it show that every vertex over one F3
index in the infinite folded core has been identified. Those are the
actual missing steps.

## Scoped folding and cover experiments

`stallings_orbit_probe.py` folds the finite subgroup generated by the
eight seeds and all one-letter signed old-source images. The resulting
core has rank154,15646 vertices and154 peripheral self-loops. Literal
x1,x5,x7 belong, while literal x3 does not belong to this finite stage.
This is not a nonmembership result for K_m. The subsequent bounded
inverse-orbit search was interrupted as unproductive; its actual partial
stdout is retained without a global inference.

For a separate exact finite-cover test, a permutation representation
rho:F7->S_n and permutations q_i fixing sheet0 are required to satisfy

    rho(alpha_i(x_j)) = q_i rho(x_j) q_i^-1

for every old action and every generator. All eight rho(nu_l) must fix
sheet0. Such data define the actual semidirect-product action with the
source fixing that sheet. If rho(F7) is transitive and at least one
killed peripheral has nonidentity image, the normal subgroup rho(R)
does not fix sheet0; hence this would prove the actual marginal image
proper. Conversely, a proper closed marginal can be separated in a
characteristic finite quotient of F7, and its coset action gives this
kind of finite-cover witness in some degree. Cofinality of finite-index
characteristic subgroups is used here; a single cover degree is not
cofinal.

`search_all_S4_cover.py` checks every transitive degree-four cover of
this kind, using simultaneous conjugation by the stabilizer of sheet0
to remove duplicates. It genuinely evaluated246841344 representatives
and found no witness. The earlier identity/transposition scan is also
retained. These are bounded negative searches only. They do not prove
K_m=R and are not promoted to a formal claim.

Even a future proof of both marginal equalities would still leave the
joint interaction subgroup K^+ intersect W in attached F22. No result
here is an element of the original completed intersection K.

## Focused paired S3 test prompted by the relative-fiber counterexample

The root/CE counterexample to a broad relative special-fiber lemma is
separated by S3 times S3 acting on six cosets of its diagonal subgroup.
Motivated by that specific mechanism, `check_paired_S3_source.py` tests
two surjections F7->S3 whose eight actual seed images agree and whose
eleven actual old actions have the same implementing inner conjugators.
Their actual source-orbit image is then diagonal. For every such pair,
the program enumerates its image subgroup in S3 times S3 and all
conjugates of the four killed peripheral images, so it tests the entire
image of the normal filling kernel, not only the four initial images.

The genuine run found5250 source-invariant surjections,3753 buckets
with matching seeds and conjugators, and2238 paired candidates. None
gave a non-diagonal normal-kernel image. This is only a negative test
of the stated fixed-factor class. Factor-swapping normalizers and
other finite groups were not included, and the search was not enlarged
after this failure. No equality is inferred.
