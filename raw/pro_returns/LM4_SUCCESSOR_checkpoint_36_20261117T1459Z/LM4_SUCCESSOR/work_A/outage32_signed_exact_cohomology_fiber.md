# Exact kernel of the cohomology comparison

Conversation-level addendum to the actual signed-q3 proof; no new finite computation.

Use K0=ker(q) intersect Fhat', the actual alpha-stable quotient Fhat'/K0=Q8, its induced involution beta, and the already established Q8^beta={I,-I}. Assume the accepted (Fhat')^alpha=1. Fix w in Fhat'' with genuine prescribed matrix image q(w)=-I; c_w=w^(-1)alpha(w) is an actual K0 cocycle and represents a nontrivial class.

The kernel of H^1(C2,K0)->H^1(C2,Fhat') is EXACTLY {1,[c_w]}. Here 'kernel' means the inverse image of the distinguished trivial class in a pointed set, not a group kernel.

Indeed take a K0 cocycle c whose Fhat' class is trivial, so c=t^(-1)alpha(t) for t in Fhat'. Its q-image is I, hence q(t) is beta-fixed. If q(t)=I, then t lies in K0 and [c]=1. If q(t)=-I, write t=w k with k in K0; then c=k^(-1)c_w alpha(k), so [c]=[c_w]. Conversely both classes map to the trivial Fhat' class by construction. They are distinct, since a K0 coboundary expression for c_w would give a nonidentity alpha-fixed element w k^(-1) with q-image -I.

This exact two-element FIBER does not state that the entire H^1(C2,K0) has two elements. The actual candidate c_b of the signed-hexagon criterion belongs to this fiber because c_b=lambda alpha(lambda)^(-1) with lambda=b^(-1)u in Fhat'. Its unresolved choice between these two classes is precisely the signed obstruction.
