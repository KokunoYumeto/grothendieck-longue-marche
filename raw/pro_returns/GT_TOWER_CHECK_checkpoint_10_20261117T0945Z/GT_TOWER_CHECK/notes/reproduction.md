# Reproduction

Use Python 3.12 or a compatible Python 3 with numpy, sympy, pypdf and PyMuPDF (fitz), plus Poppler pdftoppm and a basic TeX Live installation. The exact finite calculations use integer or rational arithmetic and reductions modulo the named primes. They do not depend on random seeds or floating-point tolerances for their mathematical certificates.

Restore the supplied attachment beside this directory as background/. It is intentionally excluded from the archive. Programs that audit its exact text or original supplied code expect that relative location. `python3 code/verify_background.py` checks all manifest entries.

The integrated paper sources and bibliography are sufficient to build the PDF without the work/ contribution directory. Run `python3 code/build_pdf.py 3`. The script reconstructs a private LuaTeX package from a checksum-pinned Debian package when necessary, builds a local format and font map, runs BibTeX and three LuaLaTeX passes, and saves transcripts under notes/build/. Downloads remain outside the deliverable. `code/bootstrap_runtimes.py` also reconstructs the recorded GAP runtime for the `.g` finite-group checks; notes/gap_runtime_downloads.json records its exact package hashes.

`python3 code/update_results.py` regenerates the CSV from every numbered statement and the explicitly maintained dependency metadata. It stops on an unknown identifier rather than silently assigning a generic dependency. `python3 code/check_paper_sources.py` checks the integrated ledger, labels, references, final build log and visual-inspection hash. The contribution-only `check_tex_sources.py` expects the ghost source files in its parent work directory; its successful original execution output is retained. `python3 code/render_pdf_qa.py` renders all specified repaired regions and an eleven-page spread sample. Rendering alone is not a visual check; the actual visual observations are recorded separately in notes/typesetting_audit.md and notes/pdf_qa/manifest.json.

`code/assemble_draft.py` is the contribution-integration utility used during research. The snapshots it read are retained in notes/source_fragments/. To repeat assembly, copy those fragments to a sibling work/ directory. The assembled root sources already retain the exact integrated version and are the authoritative build input for this checkpoint.

Mathematical programs have matching .out and, where relevant, .json and .npz outputs. The scripts explicitly named at each proof's end provide its computational certificate. Large finite groups are handled through exact presentations, Schreier chains and complete linear-equation criteria; an enormous group order is not a claim that every group element was explicitly stored. Archive-source downloads are reading material, excluded from the ZIP; their extraction code and metadata are retained.

For a GAP check with research-relative `Read(...)` paths, use `python3 code/run_gap_check.py check_descent_central_full.g`. This reconstructs the original `work/centralizer_code`, `work/tower_code` and `work/ghost_code` layout in a temporary working directory, runs the complete calculation, and retains its transcript and changed certificates in `notes/reproduced/check_descent_central_full/`. The archived originals are not rewritten. An initial `python3 code/bootstrap_runtimes.py gap` restores the checksum-pinned GAP 4.14 runtime when no installed GAP is available. The same runner accepts other archived `.g` basenames. The independent Python check `python3 code/check_central_certificate.py` verifies the exact field ranks and presentation sizes in the resulting canonical-cover certificate.


The fifth-hour root replays are `run_quaternion_reproduction.py`, `run_quaternion_homology_reproduction.py` and `run_quaternion_compact_reproduction.py`. The first reconstructs the rank-nine surface action; the second reconstructs the compressed homology image and the actual orthogonal group certificates; the third constructs the compact ideal, all centralizer equations, the literal rank73 source-word map and both augmentation-square kernels. Their separate `verify_quaternion_affine_census.py`, `verify_quaternion_compressed_census.py` and `verify_quaternion_compact_census.py` programs exhaust every finite affine vector and all corresponding source rows. Run the replay before its matching verifier.

The exact integral Bass--Serre module calculation is independently repeated by `run_relation_module_reproduction.py` after the marked GAP data export. The final ternary restriction is replayed with `python3 code/run_gap_check.py check_ternary_restriction.g`; it reconstructs the exact power--conjugate presentation and marked cocycles, then checks the actual quotient and all central cubes/commutators. The source central-extension computation is retained separately; the replay does not falsely claim to recompute its whole cohomology space.
