# Work records

The authoritative deliverables are the combined transcription, the 44 page fragments, the final doubts file, the inventory, the research notes, and `progress.log` at the archive root.

`audit_notes.md`, `doubts_rows.md`, `notation_rows.md`, and `research_leads.md` preserve the working record made before the context was opened. Some provisional readings in these records were changed during the second visual audit, before the freeze; the final doubts file and the frozen page fragments carry the resulting readings. These earlier records are included to document the work and its progression.

`frozen.sha256` records the exact 45 transcription hashes frozen before context opening. `latex_validation.md` and `latex_compile.log` document the successful pre-freeze compilation. The compilation used content-preserving definitions of the editorial macros and checked TeX syntax and diagram labels; it did not replace the visual audits.

`context_searches.md`, `research_checks.md`, `research_checks.json`, and `research_validation.md` document the post-freeze research work. All research content, source comparisons, and mathematical checks were written by the root reader. Infrastructure assistance was limited to the TeX runtime, package-validation scripts, and final packaging helpers.

The original images, input archives, and supplied context files are excluded. Context locators in the notes and search log refer to the separately supplied context archive.
