## Package notation table

This table records the visual conventions used in the frozen transcription. The second visual audit covered every scan, followed by a comparison of repeated signs before any research context was opened. Earlier provisional alternatives in the page records are historical observations; the current page files and the table below take precedence.

## Current unresolved readings

The following register is generated from every current `\unsure{...}` marker, including nested markers, and every `\illegible{n}` span. Approximate line numbers refer to the individual page fragment, not to a conjectured physical line numbering. A confidence of **low** is assigned conservatively when no exact matching page-record confidence exists; it does not assert that all such alternatives are equally likely.
