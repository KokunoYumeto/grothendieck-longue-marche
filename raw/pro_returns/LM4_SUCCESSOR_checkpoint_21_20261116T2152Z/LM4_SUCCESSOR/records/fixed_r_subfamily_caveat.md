canonical r-normalizer. Its linear-span failure concerns only that restricted
family. It is **not** a full obstruction to the requested negative involution.
Legitimate homogeneous changes of the r-frame were omitted from that family.

we can retain the conjugated involution in an S3 lift across the actual pro-2
extension by A.16. Coprime conjugacy of the order-three complements then matches
the lifted factor with the actual r. This gives an r-normalizer having the
required literal base value and the cross-section conjugacy property.

For the earlier compact base construction, retain the transporter as an
additional closed variable. Nonemptiness at common finite refinements gives
a compatible base together with its transporter. This is an existence
refinement, not an assertion about every arbitrary earlier choice of frame.
