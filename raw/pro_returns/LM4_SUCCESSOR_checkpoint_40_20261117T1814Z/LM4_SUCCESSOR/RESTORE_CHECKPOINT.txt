LM4_SUCCESSOR checkpoint restoration

This ZIP retains every logical deliverable and all research/version evidence.
The main paper PDF, source text, code and records retain their original paths
inside three ordinary TAR containers. No custom restoration program is needed.

1. Extract this ZIP into an empty directory.
2. From that directory, run these three standard commands:

   tar -xf LM4_SUCCESSOR/verification_images.tar
   tar -xf LM4_SUCCESSOR/historical_documents.tar
   tar -xf LM4_SUCCESSOR/historical_data.tar

3. Open LM4_SUCCESSOR/LM4_SUCCESSOR_paper.pdf and the accompanying report.

The current records/checkpoint_38_contents_sha256.tsv manifest, directly
available in the ZIP, lists every original logical file's byte count and SHA256.
The current packaging JSON binds each storage container separately. Standard
TAR hard links preserve identical contents at every original path. The included
verification programs check full logical coverage, historical retained bytes,
and native system-TAR restoration. Both main research questions remain Open.
