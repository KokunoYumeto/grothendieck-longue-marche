# Independent image-only reading

Read only your assigned audit packet: `page.jpg` and `boxes.tsv`. You have not read this page before. Do not read its first-pass packet, either witness, the consolidated page, another reader's report, `_first.tsv`, any comparison or the edition's notes. The image and non-leading box list are the only evidence supplied. General transcription conventions below are procedural, not candidate readings.

For every listed box, in order, use Pillow to crop the given original-pixel coordinates once, enlarge with LANCZOS to roughly 2000–3000 pixels across, apply autocontrast and optional sharpening, and rotate oblique writing when useful. Save the result as `edition/crops/second_145_scanNNN_Bxx.png`. Inspect every crop directly; use no OCR or other recognition software. Read the complete requested passage, including punctuation, cancellation, insertion, numeric indices, signs and uncertainty. Marginal boxes may include incidental main text: read the marginal passage; identify any unavoidable clipped text in a separate brief note, without inventing continuations.

Write your independent readings before comparison, to `edition/second/145_scanNNN_second.tsv`, UTF-8 tab-separated columns `box`, `reading`, exactly one row per box in its given order. Use a TSV writer so embedded newlines and tabs are quoted correctly. Preserve your file unchanged after submission. Do not inspect `_first.tsv` or run the comparison yourself.

Conventions: source language and spelling are preserved; use ordinary LaTeX for math, `\deleted{...}`, `\inserted{...}`, `\margin{...}`, `\uline{...}`, `\uuline{...}`, `\mspage{n}` for handwritten page numbers, `\unsure{reading}` or `\unsure{reading|alternative}` for genuine ambiguity, and `\illegible{n}` only for physically unreadable prose. Keep incomplete formulas and unmatched source parentheses. A cancelled uncertain word stays uncertain unless every letter is visible. Do not expand abbreviations or silently repair mathematics. Source diagrams, if present in a box, use TikZ or tikz-cd rather than prose.

Save a JSON crop manifest alongside the TSV, with box ID, crop path, original coordinates, rotation if used, and any brief uncertainty or clipping observations. Record only what you saw. Do not change the edition or any first-pass file. Return counts and paths, then wait for a new assignment.
