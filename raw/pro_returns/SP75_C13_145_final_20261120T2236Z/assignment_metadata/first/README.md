# Historical first-reading assignment metadata

The 24 page directories contain the 72 unchanged `geometry.json`, `guidance.md` and `notation.md` files supplied to the first readers in their individual assignment packets. These records preserve the geometry, instructions and evolving notation information available to each reader at that time.

The page-specific notation files are historical assignment snapshots. They can differ from one another and from the final editorial notation table. The current edition’s notation is recorded in `notation.md` at the edition root and in `SP75_C13_145_doubts.md`; these historical snapshots do not replace it.

The supplied page images, generated halves, witness texts and difference-row extracts are excluded. Audit box-list duplicates are also omitted here because identical records are already preserved in `second/`.

`reader_reports/assignment_metadata_packaging_receipt.json` records each original path, packaged path, byte count and matching source/copy SHA-256 hashes. The earlier first-reading script-copy receipt remains unchanged; its statement that these snapshots had been excluded records the earlier packaging state, superseded by this separately authorized inclusion.
