# Notation table

| Recurring ink | LaTeX | Reading policy / examples |
|---|---|---|
| Double quotation marks | two backticks, two apostrophes | Typed and handwritten English quotation marks; no substitution of guillemets. |
| Hom subscript gr | `\operatorname{Hom}_{\mathrm{gr}}` | Distinguish an underlined sheaf Hom from ordinary Hom; crowded subscripts carry doubt marks. |
| Category of biextensions / classes | `\operatorname{BIEXT}` / `\operatorname{Biext}` | Preserve case, underlining, and semicolon separately. |
| Underlined Ext, degree 1 | `\underline{\operatorname{Ext}}^1` | Superscript 1 distinguished from prime. |
| Exclamation-mark exponent | `^!` | Explicitly explained as an exclamation mark in 36/056; never a prime. |
| Prime on j, A | `j'`, `A'` | A single slanting stroke; distinguish from ! and *. |
| Pullback asterisk | `^*` | Delta and morphism pullbacks; keep separate from superscript !. |
| Underlined NS | `\underline{\operatorname{NS}}` | Preserve base indices A/S and arguments as written. |
| P / Pic | `\unsure{P|\operatorname{Pic}}` | Crowded initial symbol on 36/058; do not expand on mathematical grounds. |
| Hat on action sigma | `\hat\sigma` | Typed pages 36/053, 055; not a hat on G. |
| Outlined affine-space letters | `\mathbb A`, `\mathbb B` | Typed page 36/055. |
| Underlined small o | `\underline{o}` | Typed structure rings; not silently converted to script O. |
| Plain connecting stroke | `\mathbin{-}` / TikZ `dash` | Do not add arrowheads absent from the ink. |
| Isomorphism | `\xrightarrow{\sim}`, `\simeq`, `\cong` | Preserve arrow versus no arrow and number of horizontal strokes. |
| Multiplication | `\cdot`, period, or juxtaposition | Retain the visible choice in each formula. |
