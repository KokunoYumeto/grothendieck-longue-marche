# Reader output contract

Read the supplied guidance in full. Use no OCR, recognition software, web research, other page inputs or other readers' files. View page.jpg once and the already-created top.png and bottom.png once each. Halves have their original resolution and overlap; do not remake or rescale them. Read every manuscript line, including all C/H agreements. Then make exactly one tight enlarged crop per unresolved place, every C/H lexical disagreement, and every C doubt mark you resolve. Use Pillow crop + LANCZOS enlargement to roughly 2000–3000 pixels width, autocontrast and optional sharpening. Save crops in the shared edition/crops/ with scan-specific descriptive names. For every crop record original-image [x0,y0,x1,y1]. Do not take two first-reading crops of the same decided place. A crop may include adjacent related marks in one formula; document all affected places precisely.

Only read the assigned packet and these instructions. You may use the shared scripts directory to save page-specific crop code. Do not inspect other scans, other witness pages, reports, or the consolidated edition. Do not browse. The root reader will review your crops and finalize your page. Do not write the final pages/ file or append progress.log. Do not claim any mathematical verification you did not perform.

Write your proposed complete LaTeX page to edition/reader_reports/145_scanNNN.tex, using the supplied macros and witness C's page identification syntax. Preserve deletions, insertion locations, unusual abbreviations, all visible punctuation and authorial slips. Retain uncertainty where strokes do not distinguish alternatives; never silently normalize. No preamble and no TeX compilation.

Write edition/reader_reports/145_scanNNN.json containing these keys:

- scan: integer; reader: your agent name; lines_read: integer count of manuscript text/formula lines you actually read; layout: concise description.
- changes: array of objects, one per substantive locus differing from C or H. Fields: id (sNNN-01 etc), place (line/display/margin), C, H, final (exact strings, not only descriptions), ink (specific letters/strokes; which are plain and which are not), confidence (high/medium/low), kind (one of the collation kinds below), c_changed (boolean), h_changed (boolean), marked_in_H (yes/no), crop (relative path crops/...), box ([x0,y0,x1,y1]), error_category (one or more integers 1–10 from the error sheet), math_consequence (short string or empty). Include retained C against H as well as changed C, and deletion/insertion/underline differences that change the diplomatic reading. Macro spelling alone and editorial H headers/footers are excluded. Changes of certainty alone belong in decisions/doubts, but any C uncertainty resolved must have a crop.
- decisions: array for EVERY id in marks.tsv in order. Fields: id, decision (first/alternative/other/undecided), reading (exact surviving text including unsure if unresolved), ink, crop, box, confidence. A resolved mark always needs a crop. Struck doubtful text is resolved only if every letter is plain.
- doubts: array with place, reading, alternatives, confidence, reason. Include all remaining and newly introduced uncertainty.
- inventory: array with element (stable local id), kind (text/display/diagram/drawing/margin note/insertion/deletion), position, first_words_or_objects, box (original pixels), sheet_kind, hand, transcribed (yes). Include every separate block, display, insertion, deletion and margin item. Account for each C deleted/inserted explicitly.
- second_boxes: array with box (unique B01 etc), kind (reason for selection), coords ([x0,y0,x1,y1]), reading (complete exact transcription of the box in our macros). Cover EVERY insertion, marginal note, struck passage, formula having a C or proposed doubt, handwritten number, C/H word disagreement, and non-high-confidence departure from C. Combine overlapping subjects where appropriate, but keep each box tight enough for a fresh reader. Include handwritten page numbers and formula numbers. No need for second-pass images yet.
- notation: array of observations about recurring notation, with observed places and qualifications. Do not infer uniformity beyond your page.
- hand: array of observed handwriting habits, affected places, whether universal on this page, and witness misreadings caused.
- abbreviations: array of objects {form, expansion, place}.
- notes: concise English paragraphs stating what this page asserts/computes/asks, any math-guided reread, any clear authorial slip, all authorial doubt phrases, dates, manuscript page numbers. Describe claims as the author's, not as proven.
- check_events: array of {statement_id, type, outcome}; only for actual checks or use. Allowed types: targeted proof check; independent re-proof; computation or formal certificate; used and rechecked in this run; carried as background without fault found; refuted, with refined statement's id. Reading/transcribing alone is not a check; an empty array is acceptable if nothing was checked or used.
- diff_coverage: array for every input differences.tsv row, sequential row numbers starting 1, with status (substantive or macro/editorial), change_id if relevant, or explanation. Tokenization artifacts may span multiple rows; link those rows to the same substantive locus. This guards against omitted disagreements.

Collation kinds: misread word; misread symbol or index; omission; text not on the page; deletion state; insertion or placement; abbreviation expanded or spelling modernised; readable ink left as \\ill{}; drawing or diagram; other.

When done, return a short summary giving report paths, crop count, changes and remaining doubts, plus anything requiring root adjudication. Do not proceed to another page until assigned. Take sufficient time to read every line.
