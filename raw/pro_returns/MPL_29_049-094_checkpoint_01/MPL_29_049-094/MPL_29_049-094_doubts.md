# Notation table and transcription doubts

## Package notation table

| Visible sign or usage | LaTeX transcription | Reading policy |
|---|---|---|
| Inclusion map, cursive short iota (typescript formulas) | `\iota`, `\iota_a` | Distinguish from a prime or a variable v. |
| Uppercase delta and lambda basis vectors | `\Delta^\beta`, `\Lambda^\alpha` | Preserve distinct glyphs and indices. |
| Multiindex range, N with upright strokes | `\mathbf{N}_r^n` | Typeface distinction is provisional; check across the typescript pages. |
| Double quotation marks | two backticks and two apostrophes | Guillemets only when drawn. |
| Printed typescript page number | ordinary text | Not `\mspage`, which is reserved for autograph numbering. |
