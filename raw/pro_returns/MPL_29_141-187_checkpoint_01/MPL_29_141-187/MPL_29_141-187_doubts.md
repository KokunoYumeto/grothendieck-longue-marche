# Notation table and reading doubts

## Working notation table

| Written sign | LaTeX treatment | Visual caution / scans |
|---|---|---|
| Plain category letter C | `C` | Do not infer a script alphabet without a distinguishing stroke; 141. |
| Curved, descending, looped category/functor letter | `\unsure{\mathfrak{Z}}` provisionally | Alphabet and identity unresolved on 141; compare later occurrences against ink before freeze. |
| Hom with raised gr | `\operatorname{Hom}^{\mathrm{gr}}` | Raised abbreviation, not a prime; 141. |
| Pointed torsor pair | `(P,\xi)` | Distinguish xi from zeta and from the looped functor letter; 141. |
| Image of a class under u | `u_*(\alpha)` | Star is a subscript; 141. |
| Barred group | `\overline{G}` | Preserve bars in the small upper diagram; 141. |
| Double quotation marks | two backticks and two apostrophes | Use only when present; guillemets only if drawn. |
| Crossed-out words | `\deleted{...}` | Retain recoverable ink and mark unreadable remnants. |
