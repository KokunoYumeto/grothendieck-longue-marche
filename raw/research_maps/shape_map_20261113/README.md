# Shape map, 13 November 2026: where obstructions live when finite stages pass to a limit

This folder holds a working map, published as it was written. It compares how a number of results were resolved and
asks one question of each: when a statement holds at every finite stage, where does the obstruction to passing to the
limit live? The material is the ChatGPT Pro returns of this project (La Longue Marche, Les Dérivateurs, the
workbenches) and related mathematics and physics.

## Files

- `SHAPE_MAP_BLIND_FABLE_20261113.md`: the first map. Its brief did not say which pattern to look for. It gives seven
  similarities (S1 to S7), the features only some of the results have, and seven carry-overs from one result to
  another.
- `SHAPE_MAP_REVISION_20261113.md`: Revisions 1, 1a, 1b, 2 and 3, as the file stood on 13 November 2026 after
  Revision 3 (12:39 UTC). Revision 3 sorts the obstructions into five frameworks: derived colimit, derived limit,
  the Galois part against the full topos, pro-p against profinite, integral against rational. A later revision is
  added here as a new dated file.
- `KNOWLEDGE_HANDOFF_SHAPE_MAP.md`: what was read and how far, what is established, what is open, and cautions for
  the agent that continues the work.

## Status

Working notes, unrefereed. No proof in any source was checked for them. Each statement carries its status: claimed
by a return or a paper; "proved here", which means a short argument or an exact computation by the agent that nobody
has checked; open; or wrong. Where a paper was not opened, the notes say so.

The files are as the agent wrote them, except that the user's first name in file paths is replaced by "user". The
local paths in them refer to the machine the work was done on.
